# Angular — Synthèse du dimanche 4 octobre 2026

## Digest court

Journée calme côté Angular : le seul sujet de fond est la mise à jour de l'équipe sur le compilateur compatible TypeScript 7. Comme TypeScript 7 est réécrit en Go, l'API `ts.Transformer` sur laquelle repose le compilateur Angular ne fonctionne plus. L'équipe construit donc `ngp`, un préprocesseur hybride Rust + TypeScript. Une version expérimentale est promise pour la fin de l'année, sans chiffres de performance.

## Top 1 — ngp, le compilateur Angular post-TypeScript 7

- **Pourquoi** : le compilateur actuel dépend de l'API de transformation de TypeScript, inutilisable depuis un binaire Go.
- **Architecture** : analyseur Rust (oxc) en frontend, génération de code TypeScript en backend, packagé via `napi-rs`.
- **Sortie** : deux fichiers par source, `.ng.ts` (production) et `.ngtypecheck.ts` (diagnostics).
- **Calendrier** : version expérimentale « plus tard cette année », gains non chiffrés.
