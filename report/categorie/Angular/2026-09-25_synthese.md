# Angular — Synthèse du vendredi 25 septembre 2026

## Digest court

Journée à un seul sujet, mais c'est le plus structurant de l'année côté outillage Angular. L'équipe a publié son plan pour vivre avec **TypeScript 7**, le port natif en Go du compilateur TS. Verdict : l'intégration historique d'`ngc` avec les API du compilateur TypeScript **ne peut pas** survivre à la barrière de langage. Angular découple donc la compilation du type-checking et écrit un nouveau frontend en **Rust sur oxc**, baptisé **ngp** (Angular Preprocessor). Une version expérimentale est visée pour la fin d'année. Rien d'autre de neuf sur le front Angular cette semaine, donc pas de `_detail.md` gonflé artificiellement.

## Top 1 — Le compilateur Angular passe (partiellement) à Rust

- **ngp (Angular Preprocessor)** : nouveau binaire qui remplace l'intégration `ngc` ↔ API TypeScript, pensé pour cohabiter avec TS 7.
- **Architecture hybride** : frontend *analyzer* en Rust/oxc (parsing, découverte des décorateurs, graphe NgModule), backend en TypeScript (compilation des templates).
- **Deux fichiers générés par source** : `<fichier>.ng.ts` pour le runtime, `<fichier>.ngtypecheck.ts` pour les diagnostics TypeScript — en mémoire, pas sur disque.
- **napi-rs** : l'analyzer se charge en natif si un binaire existe pour ta plateforme, sinon en WASM (utile pour les IDE en ligne).
- **Pas de chiffre de perf annoncé** : l'équipe refuse de promettre le « 10× » de TS 7 tant que le build CLI complet n'est pas benchmarké.

À noter : l'équipe confirme quelques cas limites où le type-checking se comportera différemment. Ils seront documentés comme breaking changes, mais restent décrits comme exceptionnellement rares.
