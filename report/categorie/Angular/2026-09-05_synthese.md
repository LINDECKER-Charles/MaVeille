# Angular — Synthèse du samedi 5 septembre 2026

## Digest court

L'outillage bouge plus que les frameworks cette semaine. **Vitest 5.0** est sorti le 3 septembre : jusqu'à 53 % de temps gagné sur certaines configurations, une Trace View pour le Browser Mode, une API `vi.when` pour le mocking conditionnel, et deux changements de valeurs par défaut qui vont casser des suites existantes. En parallèle, Microsoft a archivé le dépôt `microsoft/typescript-go` le 1er septembre : le port Go du compilateur réintègre `microsoft/TypeScript`, ce qui referme le chantier ouvert par la GA de TypeScript 7.0 en juillet. Côté Angular lui-même, rien de publié en 48 h — la 22.2 est attendue courant septembre dans la nouvelle cadence bimestrielle.

## Top 1 — Vitest 5.0 : la performance comme sujet principal

- **Gains mesurés** : −19 % sur un monolithe de 1 280 modules, −53 % sur un projet à dépendances lourdes en `vmThreads`, −18 % en Browser Mode.
- **`vi.when`** : définir un retour par jeu d'arguments sans écrire de `mockImplementation` à la main.
- **`clearMocks: true` par défaut** : l'historique d'appels ne fuit plus d'un test au suivant.
- **Assertions asynchrones non attendues** : `expect(p).resolves.toBe(1)` sans `await` fait désormais échouer le test au lieu d'avertir.
- **Prérequis durs** : Vite ≥ 6.4.0 et Node.js ≥ 22.12.0.

## Top 2 — TypeScript : le port Go rentre à la maison

- **`microsoft/typescript-go` archivé** le 1er septembre 2026, deux mois après la GA de TypeScript 7.0.
- **Fusion dans `microsoft/TypeScript`** : un seul dépôt, un seul backlog d'issues pour le compilateur natif.
- **API programmatique stable** toujours annoncée pour TypeScript 7.1 — c'est elle qui débloque les outils tiers de type-aware linting.

Ces deux mouvements pointent dans la même direction : la chaîne d'outils front se consolide autour de binaires natifs et de dépôts uniques, pendant que les frameworks eux-mêmes ralentissent leur cadence.
