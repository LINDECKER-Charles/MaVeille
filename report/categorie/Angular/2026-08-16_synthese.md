# Angular — Synthèse du dimanche 16 août 2026

## Digest court

Week-end calme côté framework : aucun tag Angular publié depuis `22.2.0-next.2` du 13 août, déjà traité ici le 14. Le blog officiel n'a sorti qu'un récap communautaire le 14 août. Le vrai mouvement de la semaine vient de l'outillage de test front : Expedia Group a ouvert `mockql-rs`, un CLI Rust qui remplit à la volée les champs GraphQL annotés `@mock` avec des données générées par un LLM. C'est la troisième tentative publique en six mois sur le même problème, après le `@generateMock` d'Airbnb en avril et une RFC de la GraphQL Foundation ouverte en février. Les trois designs divergent, et deux d'entre eux emploient le même nom de directive pour des sémantiques incompatibles.

## Top 1 — Les fixtures de test générées par modèle

- **`mockql-rs` (Expedia Group)** : proxy autonome entre client et serveur, écrit en Rust, sous licence open source.
- **Directive `@mock(hint: "...")`** : tu annotes le champ dont le resolver n'existe pas encore, le reste part vraiment en amont.
- **`@generateMock` (Airbnb)** : même intention mais au *build*, via la codegen Niobe, avec fichier JSON et accesseurs typés.
- **RFC GraphQL Foundation** : `@mock` posé sur l'opération et non le champ, mocks stockés dans `__graphql_mocks__`, zéro requête réseau.
- **Statut Stage 0** : la RFC est un strawman sans champion — standardiser sur `@mock` aujourd'hui, c'est parier sur une lecture propriétaire.

## Top 2 — Sur le radar

- **Angular `22.2.0-next.2`** : toujours la dernière préversion publiée, pas de `next.3` ce week-end.
- **npm 12** : scripts d'installation désactivés par défaut — vérifie tes pipelines Angular CLI si ce n'est pas déjà fait.
