# Angular — Synthèse du jeudi 28 mai 2026

Angular 22 est officiellement **stable depuis le 20 mai 2026** — la nouvelle qui domine la catégorie cette semaine. L'élément le plus structurant pour ton workflow quotidien n'est pas dans les features framework déjà connues (Signal Forms, zoneless par défaut) mais dans **l'intégration native du Model Context Protocol** dans l'outillage officiel : `ng add @angular/mcp` installe un serveur que ton IDE peut interroger pour obtenir des suggestions de code Angular contextualisées à la version exacte de ton projet.

En complément, la newsletter hebdo officielle pousse l'adoption des `HttpResource` (alternative signal-first à `HttpClient` + `subscribe`) et de la nouvelle API `createComponent()` pour les composants dynamiques. Vitest devient le test runner par défaut pour les nouveaux projets.

## Top sujets du jour

- **Angular 22 stable + MCP intégré** — `ng add @angular/mcp` à installer dans ton workflow IDE. Angular 21 reste LTS jusqu'à mai 2027 mais ne reçoit plus que des fixes de sécurité.
- **HttpResource & Dynamic Components revisités** — les patterns signal-first à adopter dès maintenant sur les nouveaux écrans.
- **Vitest par défaut** — 2-3× plus rapide que Karma sur les gros monorepos. Karma passe en maintenance.
