# Angular — Synthèse du mardi 30 juin 2026

## Digest court

Écosystème Angular calme : aucune release sur les dernières 48 h. Les deux fils structurants restent le **zoneless par défaut** (zone.js retiré du template depuis la v21) et **TypeScript 7.0 RC**, dont le compilateur natif en Go devient le `tsc` officiel (analyse du 23/06). Côté agents, **A2UI 1.0 RC** continue d'avancer — des UIs pilotées par un agent et rendues en Angular (détaillé le 27/06). Le flux blog.angular.dev n'a pas pu être décodé ce matin (compression gzip) ; veille complétée par recherche ciblée.

## À surveiller

- **Zoneless par défaut** : vérifie que tes libs tierces ne dépendent plus de `zone.js`. https://angular.dev/guide/zoneless
- **TypeScript 7.0 RC** : compilateur Go, gains de build attendus sur gros monorepos (détaillé le 23/06).
- **A2UI 1.0 RC** : protocole « agent ↔ UI », à tester sur un POC avant de t'engager. https://angular.dev/roadmap
- **Signal Forms (v21)** : API de formulaires réactive, encore expérimentale.
