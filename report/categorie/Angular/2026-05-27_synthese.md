# Angular — Synthèse du mercredi 27 mai 2026

## Digest court

Angular 22 entre en RC1 et finalise la bascule vers le modèle signal-first. C'est la fin officielle de l'ère Zone.js : la Signals API devient stable, zoneless devient le défaut pour les nouveaux composants, et les Signal Forms remplacent Reactive Forms. Les Selectorless Components simplifient l'importation et la composition.

## Top 1 — Angular 22 RC1

- **Signal Forms** : modèle de formulaires natif signaux, remplace Reactive Forms, typage de bout en bout
- **Signals API stable** : `signal()`, `computed()`, `effect()`, Signal Inputs, Signal Queries — utilisables en prod sans risque
- **Zoneless par défaut** : OnPush + signal-based reactivity sans Zone.js, suppression de ~30 Ko gzipped
- **Selectorless Components** : import direct dans les templates sans selector string

Sortie attendue fin mai / début juin 2026. Migration progressive recommandée — compatibilité Zone.js maintenue pour faciliter la transition.
