# Angular — Synthèse du samedi 29 août 2026

## Digest court

Le roundup Angular du 28 août tourne autour d'un seul axe : les Signal Forms cessent d'être une API « à câbler » pour devenir une API déclarative. Deux briques stabilisées en v22 portent ce basculement. La directive `FormRoot` absorbe le `preventDefault()`, le `novalidate` et l'appel à `submit()` que tu écrivais à la main, et déplace toute la logique de soumission dans l'objet `FormOptions.submission`. En face, `provideSignalFormsConfig({ classes })` réintroduit les classes d'état CSS que les Signal Forms avaient volontairement supprimées — mais sous forme de prédicats redéfinissables au lieu du jeu `ng-*` figé des Reactive Forms. Les deux sont marqués stable depuis v22.0 : c'est le bon moment pour reprendre une migration Reactive → Signal qui aurait calé.

## Top 1 — `FormRoot` : la soumission devient déclarative

- **`[formRoot]`** : la directive pose `novalidate`, appelle `preventDefault()` et invoque `submit()` à ta place.
- **`FormOptions.submission.action`** : une fonction `async (field, detail)` ; retourner `undefined` = succès, retourner un objet = erreur.
- **Routage d'erreurs** : `{ message, fieldTree: f.email }` cible un champ précis ; un tableau reporte plusieurs erreurs serveur d'un coup.
- **`submission.onInvalid`** : s'exécute après le marquage `touched`, donc idéal pour `focusBoundControl()`.
- **`ignoreValidators`** : `'pending'` (défaut) soumet pendant qu'un validateur async tourne — passe à `'none'` si tu valides côté serveur.

## Top 2 — `provideSignalFormsConfig` : les classes d'état reviennent, programmables

- **Aucune classe par défaut** : la directive `FormField` ne pose plus rien, ce qui casse silencieusement le CSS d'une migration Reactive → Signal.
- **`NG_STATUS_CLASSES`** : preset importé de `@angular/forms/signals/compat` qui restitue `ng-valid`/`ng-invalid`/`ng-touched`/`ng-dirty`/`ng-pending` en une ligne.
- **Prédicats libres** : `{ 'app-error': ({ state }) => state().invalid() && state().touched() }` centralise une règle UX impossible à exprimer en Reactive Forms.
- **Piège de version** : la signature du prédicat a changé entre v21 et v22 — les tutoriels de fin 2025 (`s => s.touched()`) ne compilent plus.

Les deux APIs sont complémentaires : `formRoot` répond au « quand soumettre », `provideSignalFormsConfig` au « à quoi ça ressemble ». C'est exactement l'axe du billet Angular du 28 août.
