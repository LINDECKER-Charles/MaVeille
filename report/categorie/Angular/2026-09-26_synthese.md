# Angular — Synthèse du samedi 26 septembre 2026

## Digest court

Journée calme côté Angular pur — pas de nouvelle version ni de RFC cette fois — mais un signal fort côté écosystème TypeScript : Vercel Labs publie scriptc, un compilateur qui transforme du TypeScript typé en binaire natif sans moteur JavaScript embarqué. Démarrage en 1,78 ms contre 21 ms pour Bun et 62 ms pour Node, au prix d'un dynamisme limité — la plupart des packages npm classiques restent hors de portée sans le mode `--dynamic`. Un signal à suivre pour l'outillage CLI de l'écosystème Angular/Nx plus que pour l'appli elle-même.

## Top 1 — scriptc, le compilateur qui vire le moteur JS du binaire

- **scriptc 0.0.16 (Vercel Labs)** : TypeScript compilé en C / LLVM / assembleur / WASI, sans Node ni V8 dans le binaire final.
- **Démarrage** : 1,78 ms vs 21,29 ms (Bun) et 61,78 ms (Node) — mémoire idle de 1,9 Mio.
- **Limite** : le code dynamique (la plupart des packages npm) doit tourner dans un moteur `quickjs-ng` embarqué, avec un coût CPU réel.
