# Angular — Synthèse du mercredi 8 juillet 2026

## Digest court

Semaine calme côté releases — pas de nouvelle version — mais l'équipe Angular pousse deux pratiques concrètes via son *Community Weekly* du 7 juillet. D'abord le **Vitest « Full » Browser Mode** : tester tes composants dans un vrai navigateur (Chromium) au lieu de `jsdom`, pour coller au comportement réel de l'utilisateur. Ensuite les **Extended Diagnostics** du compilateur : une famille de règles qui attrapent les bugs de *template* au build, avant la prod. Les deux tournent déjà sur Angular 21, sans dépendance exotique.

## Top 2 — Testing et diagnostics Angular

- **Vitest Full Browser Mode** : exécute tes tests de composants dans un navigateur réel via `@vitest/browser` + Playwright, `jsdom` remisé au placard.
- **Extended Diagnostics** : `angularCompilerOptions.extendedDiagnostics` transforme les pièges de template (banane dans la boîte, `??` inutile) en warnings ou erreurs de build.
- **À retenir** : deux gains de qualité « gratuits », déjà dans le SDK Angular 21, sans migration lourde.
