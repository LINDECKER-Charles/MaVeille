# Angular — Synthèse du lundi 14 septembre 2026

## Digest court

Week-end calme côté Angular : le blog officiel n'a rien publié depuis le 2 septembre, et npm reste sur `@angular/cli` 22.1.8. Le seul vrai mouvement de l'écosystème front vient de Meta, qui ouvre en bêta **Astryx**, son design system React mûri huit ans en interne et déjà déployé sur plus de 13 000 applications. L'angle intéressant n'est pas le catalogue de 150 composants : c'est que le système a été conçu dès le départ pour être piloté par des agents, via une CLI dédiée et un endpoint MCP. C'est le premier design system d'envergure qui traite l'agent comme un consommateur de premier rang, au même titre que le développeur.

## Top 1 — Astryx : Meta ouvre son design system React, pensé pour les agents

- **Astryx bêta, licence MIT** : plus de 150 composants accessibles, React 19 minimum, tokens CSS centralisés, thèmes et mode sombre inclus.
- **StyleX sous le capot** : compilateur CSS-in-JS au build qui sort du CSS atomique déterministe et sans collision ; le paquet `@astryxdesign/core` distribue le CSS **déjà compilé**, donc aucun plugin de build à adopter.
- **Double surface de style** : prop `xstyle` typée à la compilation pour le chemin StyleX, `className` natif conservé pour interopérer avec Tailwind, CSS Modules ou une feuille classique.
- **Éjection assumée** : la commande CLI `swizzle` sort le code source complet d'un composant dans ton dépôt — flexibilité maximale, maintenance à ta charge.
- **Agent-ready** : `@astryxdesign/cli` et un endpoint MCP exposent le système aux assistants de code ; des portages communautaires existent déjà vers Svelte 5 et Flutter.

Le point de vigilance relayé par la communauté porte sur la gouvernance long terme d'un projet sponsorisé par Meta — un réflexe sain avant d'adosser une couche UI entière à un dépôt d'éditeur.
