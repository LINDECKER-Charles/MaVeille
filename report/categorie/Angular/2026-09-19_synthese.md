# Angular — Synthèse du samedi 19 septembre 2026

## Digest court

Le framework Angular lui-même est resté silencieux cette semaine : la 22.2.0-rc.0 est sortie le 16 septembre sans annonce éditoriale, et le blog officiel n'a rien publié depuis le 2 septembre. En revanche l'écosystème front a bougé fort sur deux fronts qui te concernent directement en tant que backend qui livre du HTML ou pilote une CI front. htmx est passé en 4.0 avec une réécriture complète sur `fetch()`, des morphing swaps natifs et surtout un changement d'héritage d'attributs qui casse silencieusement les tokens CSRF. Et SolidStart 2.0 a abandonné Vinxi pour bâtir directement sur l'Environment API de Vite 8 — avant d'être mis en maintenance quelques jours plus tard, un signal net sur la façon dont les méta-frameworks se recentrent dans leur core.

## Top 1 — htmx 4.0, la réécriture qui casse en silence

- **Transport `fetch()`** : `XMLHttpRequest` abandonné, streaming natif débloqué, script toujours autour de 14 Ko.
- **Morphing swaps intégrés** : `idiomorph` embarqué, le focus des inputs et l'état du DOM survivent aux remplacements.
- **`hx-partial`** : une seule réponse serveur met à jour plusieurs cibles, en remplacement propre des out-of-band swaps.
- **Héritage explicite** : un attribut parent ne descend plus qu'avec le suffixe `:inherited` — ton `hx-headers` CSRF devient un 403 silencieux.
- **Migration outillée** : `npx htmx.org@4.0.0 upgrade-check -- ./templates`, publication sous le tag npm `next`, 2.x supporté indéfiniment.

## Top 2 — SolidStart 2.0, puis la retraite

- **Vinxi supprimé** : le build repose désormais sur l'Environment API de Vite 8 et sa chaîne Rolldown.
- **Configuration déplacée** : `app.config.ts` disparaît, tout remonte dans `vite.config.ts`. Node.js 24 requis.
- **FOUC corrigé** : les styles des composants lazy sont rendus côté serveur, plus de flash de contenu non stylé.
- **Mise en maintenance** : Solid 2.0 RC absorbe les server functions, la couche de service et le routage fichier — « Start mode replaces SolidStart ».

Angular 22.2 stable est attendu sur la fin septembre ; la rc.0 du 16 n'a pas encore de notes de version publiques exploitables.
