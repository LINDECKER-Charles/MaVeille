# Tech — Synthèse du dimanche 20 septembre 2026

## Digest court

Deux sujets structurants ce week-end, à l'opposé l'un de l'autre. Côté données, PlanetScale publie **TIN**, une extension de recherche plein texte pour Postgres qui atteint 8× à 541× le débit des alternatives — non par une astuce de compression, mais parce qu'elle utilise le `ctid` natif de Postgres comme identifiant de document, ce qui rend l'intersection de listes de postings vectorisable en AVX2. C'est un cas d'école de ce qu'on gagne en épousant les structures de son hôte plutôt qu'en les recouvrant. Côté plateformes, GrapheneOS documente qu'Android 17 QPR1 ajoute de nouvelles API pour développeurs **sans publication dans AOSP** — une première depuis Honeycomb (3.x). Google annonce une convergence en QPR2 en décembre 2026, mais le fait qu'un cycle entier d'API soit exclusif à Pixel change la nature du contrat AOSP.

## Top 1 — TIN : recherche plein texte dans Postgres, et pourquoi le `ctid` change tout

- **GA immédiate** sur les bases Postgres et Neki de PlanetScale ; `CREATE INDEX … USING tin(col)` puis `WHERE col ==> 'mots'`
- **Ranking BM25**, TINQL avec booléens, phrases, fuzzy, préfixes joker, requêtes de proximité, `COUNT(*)` exact
- **Postings = `ctid`** au lieu d'identifiants séquentiels : aucune table de correspondance, aucune renumérotation à la fusion de segments
- **Bitmaps à deux niveaux** (page puis offset) qui tiennent dans un registre AVX2/AVX-512 → intersections et unions en instructions vectorielles, comptage par `POPCNT`
- **Chiffres** : 199 QPS contre 7,9 pour ParadeDB en requêtes mixtes top-10 ; 242 contre 0,4 pour le GIN natif en conjonction/phrase ; index construit en 8 min 10 contre 2 h 09 pour GIN

## Top 2 — Android 17 QPR1 ajoute des API hors AOSP

- **Première depuis Android 3.x** : des API applicatives arrivent dans une release non publiée dans l'Android Open Source Project
- **Cause structurelle** : depuis Android 16, les QPR1 et QPR3 ne sont plus publiées dans AOSP ; c'est la première fois que Google y ajoute des API
- **Conséquence immédiate** : les API sont exclusives à Pixel OS, indisponibles pour les autres constructeurs et pour les forks comme GrapheneOS
- **Convergence annoncée** en QPR2, décembre 2026 — soit un trimestre d'avance pour Pixel
