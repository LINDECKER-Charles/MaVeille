# Tech — Synthèse du lundi 14 septembre 2026

## Digest court

Trois sujets ce week-end, et un fil commun : on resserre les périmètres. Homebrew 7.0.0 remplace Bubblewrap par Landlock sur Linux, coupe le réseau pendant la phase d'installation et intègre un scanner de vulnérabilités adossé à une base d'avis au format OSV — au passage, Intel macOS passe en Tier 3 et macOS 10.15 disparaît. Cloudflare teste le Cache Transcoding, qui compresse en Zstandard le texte non compressé avant écriture disque et gagne un facteur 2,8 sur le contenu éligible. Et The New Stack revient sur le vrai angle mort de MCP : ce n'est pas le protocole qui est cassé, ce sont les permissions en dessous, faute d'identité propre aux agents.

## Top 1 — Homebrew 7.0.0 : Landlock, `brew vulns` et Intel en Tier 3

- **Sandbox Linux** : Bubblewrap remplacé par **Landlock** — aucune dépendance, aucune permission Docker élevée, ABI 2 dès Linux 6.1.
- **Phases séparées** : `fetch` télécharge avec réseau et cache écrivable, puis `install` coupe le réseau et passe le cache en lecture seule.
- **`brew vulns` intégré** : scanner adossé à la nouvelle **advisory database** Homebrew, format OSV, licence CC0, données OSV.dev.
- **Ruptures immédiates** : macOS 10.15 supprimé, Intel macOS et macOS Sonoma 14 en Tier 3 sans nouvelles bottles, image `ghcr.io/homebrew/ubuntu22.04` retirée, `Homebrew/actions/*@master` supprimé.
- **BrewUI** : interface graphique macOS officielle, qui affiche les commandes `brew` sous-jacentes.

## Top 2 — Cloudflare Cache Transcoding : Zstandard sur le cache disque

- **Facteur 2,8** de réduction sur le contenu éligible, pour un surcoût CPU payé **une seule fois** à l'entrée en cache.
- **Périmètre strict** : seulement du texte compressible non compressé, réponse en succès, taille connue, **≥ 4 KiB** ; exclut les requêtes par plage et le binaire.
- **Le seuil est un arbitrage** : il évite de traiter une myriade de petits objets en ne sacrifiant qu'environ 1 % des données éligibles.
- **Stack** : Zstandard plus **Pingora**, le proxy Rust maison. Prototype, pas encore généralisé.

## Top 3 — MCP : le problème n'est pas le protocole, ce sont les permissions

- **Deux motifs** identifiés par les chercheurs : le *tool poisoning*, où la description d'un outil porte des instructions cachées, et le *confused deputy*, où l'agent hérite de plus de confiance que la tâche n'en exige.
- **Identité empruntée** : l'agent n'a pas d'identité propre, il hérite du périmètre et souvent du credential littéral de celui qui l'a lancé.
- **OAuth inadapté** : un modèle de consentement bâti pour un humain devant une boîte de dialogue, appliqué à un processus qui n'en a pas.
- **La durée de vie devient une entrée** : des agents qui vivent des semaines ne peuvent pas porter les mêmes droits qu'un script de cinq minutes.
