# Tech — Détail du samedi 6 juin 2026

## 1. Cisco SD-WAN CVE-2026-20245 — 7e zero-day SD-WAN 2026, exploitation active, aucun patch disponible

**Source :** Help Net Security — https://www.helpnetsecurity.com/2026/06/05/cisco-sd-wan-cve-2026-20245-0-day-exploited/
**Date :** 5 juin 2026

### Contexte

Depuis le début de 2026, la série Cisco Catalyst SD-WAN Manager est touchée par une cascade de vulnérabilités. CVE-2026-20245 est la 7e faille zero-day divulguée cette année sur ce produit, et la situation se répète : exploitation confirmée avant tout patch, divulguée par Mandiant (Google Cloud) dans le cadre d'une investigation d'incident. Les acteurs se servent des credentials volés via les failles précédentes pour escalader les privilèges.

### Ce qui change concrètement

**Nature de la faille :**
- Command injection dans la CLI de Cisco Catalyst SD-WAN Manager.
- Un attaquant avec des **privilèges netadmin** peut uploader un fichier crafté qui exécute des commandes arbitraires en **root**.
- CVSS : **7.8** (High).

**Conditions d'exploitation :**
- L'attaquant a besoin de credentials netadmin — souvent obtenus en chaînant CVE-2026-20182 ou CVE-2026-20127 (des failles précédentes de la même série), ou via des credentials compromis.
- Périmètre affecté : **toutes les topologies de déploiement** Cisco Catalyst SD-WAN (on-prem, Cloud-Pro, Cisco Managed Cloud, FedRAMP).

**Exploitation observée :**
- Cisco PSIRT a confirmé l'exploitation après un signalement de Mandiant.
- Des changements de configuration ont été poussés sur des équipements edge dans les incidents documentés.

**Statut du patch :**
- **Aucun patch, aucun workaround officiel** au moment de la divulgation.
- Cisco recommande : durcissement des accès CLI, revue des comptes netadmin, collecte de logs pour investigation forensique.

### Pourquoi ça compte pour toi

Si ton infrastructure (ou celle de tes clients) inclut des équipements SD-WAN Cisco, c'est une action immédiate : audite qui possède des privilèges netadmin sur le Manager, vérifie s'il y a eu des activités CLI inhabituelles récentes, et collecte les logs avant rotation. Sans patch à appliquer, la mitigation passe par le durcissement du contrôle d'accès.

### Points de vigilance

- La chaîne de compromission (faille précédente → credential netadmin → CVE-2026-20245 → root) signifie qu'une organisation qui a déjà patché les CVE précédentes **mais dont les credentials ont pu fuiter entre-temps** reste exposée.
- Surveille les IoC publiés par Mandiant via les bulletins CISA/Cisco Talos dans les prochains jours.

## 2. Patch Tuesday juin 2026 — Deadline Secure Boot 26 juin + Exchange CVE-2026-42897 en exploitation

**Source :** Help Net Security — https://www.helpnetsecurity.com/2026/06/05/june-2026-patch-tuesday-forecast/
**Date :** 5 juin 2026

### Contexte

Le Patch Tuesday de juin 2026 est prévu le **9 juin**. Le forecast de Help Net Security met en évidence deux points de tension : la deadline absolue Secure Boot du 26 juin (pour les organisations qui n'ont pas finalisé le déploiement des certificats Secure Boot en mai), et un Exchange Server RCE (CVE-2026-42897) déjà exploité avant que le patch ne soit disponible.

### Ce qui change concrètement

**Exchange Server CVE-2026-42897 :**
- RCE (Remote Code Execution) sur Exchange Server, signalée comme **exploitée in-the-wild** avant le 9 juin.
- Un correctif est attendu dans le Patch Tuesday du 9 juin — il devra être déployé en priorité absolue dès disponibilité.
- Les organisations qui utilisent Exchange on-premise (encore nombreuses en entreprise mid-market) sont directement exposées.

**Deadline Secure Boot — 26 juin 2026 :**
- Le 26 juin est la **date limite absolue** pour valider et déployer les certificats Secure Boot dans les environnements Windows.
- Les organisations qui n'ont pas complété cette étape en mai se retrouvent en mode urgence avec très peu de temps de test et de validation.
- Le Patch Tuesday du 9 juin est la dernière opportunité pour déployer les mises à jour préparatoires avant la deadline.

**Autres éléments attendus :**
- Correctif pour les erreurs d'installation de KB5089549 sur Windows 11.
- Mises à jour standard OS, Office et SharePoint.

### Pourquoi ça compte pour toi

Si tu gères ou supervises des serveurs Exchange on-prem, applique le patch CVE-2026-42897 immédiatement après le 9 juin — une RCE exploitée en amont ne peut pas attendre les cycles de test habituels. Sur le Secure Boot : si ton organisation n'a pas encore déployé les certificats, c'est l'action numéro 1 de la semaine prochaine — le 26 juin laisse 17 jours, incluant un weekend.

### Détails techniques

- Le Patch Tuesday de juin couvre environ 291 CVEs au total dans le Security Update Guide, dont 268 sont des republications Edge/Chromium couvertes par les updates navigateur normales.
- Les 23 CVEs « genuinement nouvelles » incluent Exchange, Windows, et des composants cloud patchés côté serveur par Microsoft.
