# Tech — Synthèse du dimanche 23 août 2026

## Digest court

Trois sujets, une même question de fond : où s'arrête vraiment la frontière que tu crois avoir posée. Christopher Domas publie `skitter-creek-bath-salts`, un outil qui contourne les protections mémoire d'un processeur non pas en les attaquant mais en passant dessous — en reprogrammant les registres de traduction du contrôleur DRAM, sous les barrières qui filtrent les adresses physiques. Microsoft, lui, a divulgué le 20 août CVE-2026-69836, une RCE à CVSS 10,0 sur Entra ID, exploitée dans la nature et déjà corrigée côté service : rien à patcher, et donc rien à vérifier non plus. Enfin Cloudflare annonce Kitesurf, un moteur de navigateur pour agents, écrit en Rust et exécuté en WebAssembly sur Workers, qui parle le Chrome DevTools Protocol sans embarquer Chromium.

## Top 1 — `skitter-creek-bath-salts` : casser l'isolation mémoire par en dessous

- **Le principe** : les registres de traduction du contrôleur mémoire vivent *sous* les barrières de sécurité (EPT hyperviseur, limites TSEG du SMM, carveouts privés du PSP), qui ne valident que l'adresse physique non traduite.
- **Le levier** : modifier des bits de configuration comme `BankSwizzleMode` change le calcul des coordonnées banque/ligne/colonne en DRAM — l'accès atterrit silencieusement dans une enclave protégée.
- **La chaîne** : module noyau qui désactive les cœurs non-boot, purge les caches, préchauffe les TLB et coupe les interruptions ; puis résolution de la permutation d'adresses par arithmétique de corps de Galois et solveur SMT.
- **Ce qui devient lisible** : SMRAM, tables de firmware PSP, zones de sauvegarde CC6, buffers de patch de microcode.
- **Portée réelle** : nécessite le Ring 0, et vise surtout les familles AMD 14h, 15h et 16h.

## Top 2 — CVE-2026-69836 : CVSS 10,0 sur Entra ID, et rien à patcher

- **Nature** : désérialisation de données non fiables (CWE-502) menant à une exécution de code à distance non authentifiée. Publiée le 20 août 2026.
- **Statut** : exploitée dans la nature d'après l'avis Microsoft, entièrement mitigée côté service avant divulgation publique. Aucun code d'exploitation public.
- **Ce qui change** : Entra ID est un service opéré par Microsoft — tu ne peux pas patcher, tu ne peux que chercher des traces.
- **Le piège** : « aucune action client requise » ne veut pas dire « aucune action de détection requise ».

## Top 3 — Cloudflare Kitesurf : un navigateur écrit pour les agents, pas pour les humains

- **Architecture** : chaque page ou iframe hors-processus tourne dans un Dynamic Worker isolé, avec son propre environnement JavaScript et son propre DOM.
- **Briques** : moteur de rendu Rust Blitz (DioxusLabs) et parseur CSS Stylo (Servo/Firefox), le tout en WebAssembly sur Workers.
- **Compatibilité** : le Chrome DevTools Protocol est supporté, donc Playwright et Puppeteer peuvent le piloter.
- **Limites assumées** : ni vidéo, ni WebGL, ni challenges anti-bot TLS réalistes, ni sessions authentifiées longue durée. Ce n'est pas un remplaçant de Chromium.
- **La controverse** : Cloudflare vend du blocage de scraping IA et construit un outil de scraping IA. Le code n'est pas encore ouvert.
