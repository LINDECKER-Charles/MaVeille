# Tech — Synthèse du mardi 25 août 2026

## Digest court

Deux failles à traiter aujourd'hui visent des dépendances que tu tires sans y penser. NLTK cumule cinq CVE publiées le 23 août, dont une exécution de code à distance à 8,8 via son `AllowlistUnpickler` — le composant censé rendre le dépicklage sûr. Spring AI 2.0.0 expose son transport MCP Streamable HTTP sans authentification par défaut et sans limite de rétention de sessions : déni de service non authentifié à 7,5. Côté outillage, JetBrains a sorti hier Junie Local, un agent de code qui tourne entièrement hors ligne — au prix d'un Mac M5 avec 64 Go de mémoire unifiée.

## Top 1 — Failles à traiter aujourd'hui

- **CVE-2026-71513 (NLTK, 8,8)** : RCE par désérialisation dans `AllowlistUnpickler`, versions 3.10.0 à 3.10.2. Correctif en 3.10.3.
- **Grappe NLTK** : quatre autres CVE le même jour — traversée de chemin via symlink, lecture de fichier arbitraire, DoS par récursion, téléchargement de code sans vérification d'intégrité.
- **CVE-2026-59279 (Spring AI 2.0.0, 7,5)** : transport MCP Streamable HTTP sans auth par défaut ni plafond de sessions.

## Top 2 — Ce que ces deux cas t'apprennent

- **Une allowlist de dépicklage n'est pas un bac à sable** : le contournement est la classe de bug attendue, pas l'exception.
- **Un serveur MCP est un serveur HTTP** : rate limiting, auth et TTL de session ne sont pas optionnels parce que « c'est du MCP ».

## Top 3 — Junie Local : l'agent de code entièrement hors ligne

- **Qwen3.6-27B en 4 bits** sur un moteur maison basé sur `mlx-vlm`, pas de Ollama ni de LM Studio à installer.
- **`/local`** télécharge modèle et moteur, démarre le serveur et bascule l'agent automatiquement.
- **Plancher matériel** : macOS 26, Apple M5 ou plus récent, 64 Go de mémoire unifiée, ~20 Go de téléchargement.
