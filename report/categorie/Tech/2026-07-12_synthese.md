# Tech — Synthèse du dimanche 12 juillet 2026

## Digest court

Deux sujets de sécurité qui visent directement les devs. D'abord **OpenClaw** : un chercheur montre qu'un simple message WhatsApp peut faire exécuter du code sur l'hôte de cet assistant IA, en chaînant trois failles (injection de commande + contournement de la denylist de bind-mounts). Ensuite **TeamPCP**, une opération supply-chain qui a piégé Trivy, Checkmarx KICS, LiteLLM et le SDK Telnyx pour moissonner plus de 500 000 identifiants CI/CD — le carburant du ransomware VECT. Le mécanisme LiteLLM (un `.pth` Python exécuté au démarrage) mérite que tu saches le repérer.

## Top 2 — Failles à comprendre et traiter

- **OpenClaw WhatsApp-to-Host** : 3 avis GHSA (CVSS 8.8 / 8.8 / 8.4), corrigés en 2026.6.6 ; monter `/home` ou `/var` contourne la denylist et donne clés SSH ou socket Docker.
- **Mitigations OpenClaw** : mode sandbox, retirer `exec` de l'allowlist, surveiller `git clone ext::`.
- **TeamPCP → VECT** : `litellm_init.pth` injecté dans LiteLLM v1.82.8, RAT dans Telnyx SDK 4.87.1/4.87.2, Trivy CVE-2026-33634.
- **Réflexe** : cherche `litellm_init.pth` sur tes runners, tourne toute crédential CI/CD antérieure à avril 2026.
