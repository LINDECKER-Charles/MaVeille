# Tech — Synthèse du samedi 22 août 2026

## Digest court

Pas de CVE brûlante à corriger aujourd'hui, mais trois sujets qui touchent tous à la même question : qui contrôle ce qui entre dans ton build. Debian a mis au vote une résolution générale sur les contributions assistées par LLM, avec une proposition d'interdiction pure et simple face à sept contre-propositions — un précédent qui pèsera sur les autres distributions. Flux publie Flux Mirror, un plugin CLI qui recopie images, charts Helm et artefacts OCI dans un registre que tu opères, avec vérification de signature et âge minimum obligatoire : la « diode de supply chain ». Et Docker remplace son moniteur de machine virtuelle tiers par une implémentation maison dans Docker Desktop 4.86, ce qui change la fondation runtime de tout le produit, y compris les sandboxes d'agents.

## Top 1 — Debian met au vote l'interdiction du code assisté par LLM

- **Résolution générale** : la proposition de Matthias Geiger interdirait toute contribution directe écrite avec l'aide d'un LLM ou d'un outil d'IA générative.
- **Périmètre** : paquets source Debian, logiciels natifs comme `lintian`, ressources web officielles, documentation et traductions des contributeurs.
- **Hors périmètre** : les projets amont qui utilisent l'IA, et les patchs ou correctifs de sécurité venus de l'amont.
- **Sept contre-propositions** : de l'autorisation sous conditions à une mise à jour du code de conduite, en passant par un argument climatique.

## Top 2 — Flux Mirror : faire de ton registre une diode de supply chain

- **Trois catégories d'artefacts** : images conteneur (copie octet à octet, listes multi-arch incluses), charts Helm HTTP republiés en OCI, et artefacts d'état désiré Flux.
- **Vérification avant copie** : signature Cosign et identité du signataire contrôlées ; SBOM et provenance de build reportés dans le miroir.
- **Âge minimum** : un artefact fraîchement signé est retenu, il n'est copié qu'après un délai public — la contre-mesure directe aux attaques éclair type Shai-Hulud.
- **Sélecteurs** : regex, contraintes semver, tri et top-N pour ne miroiter que les versions réellement utilisées.

## Top 3 — Docker VMM : Docker reprend la couche de virtualisation

- **Docker Desktop 4.86** : bêta publique, activé d'office sur macOS, opt-in sur Windows.
- **Gains annoncés** : démarrage de conteneur plus rapide, partage de fichiers hôte/conteneur amélioré, mémoire inutilisée rendue à l'hôte quand les conteneurs sont au repos.
- **Windows** : isolation de niveau Hyper-V visée avec des performances proches de WSL2.
- **Le vrai enjeu** : le même moteur alimente Docker Sandboxes, donc les environnements isolés des agents IA. Linux et GA sont attendus fin octobre.
