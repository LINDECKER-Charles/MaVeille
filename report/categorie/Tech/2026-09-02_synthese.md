# Tech — Synthèse du mercredi 2 septembre 2026

## Digest court

Deux sujets aujourd'hui, mais deux sujets denses. Le premier est urgent : la CISA a ajouté le 31 août **deux zero-days PaperCut NG/MF** à son catalogue KEV, exploités avant l'existence d'un correctif. Chaînées, elles donnent une exécution de code à distance **sans authentification** sur le serveur d'impression. Le mécanisme central — la *unsafe reflection* — se transpose tel quel en .NET, ce qui en fait un cas d'école utile bien au-delà de PaperCut. Le second est plus calme mais formateur : le zine de recherche binaire **tmp.0ut** a sorti son volume 5, avec notamment une plongée dans la façon dont le noyau Linux charge un exécutable. C'est le genre de connaissance qui explique d'un coup trois messages d'erreur que tu croises en conteneur.

## Top 1 — À corriger : la chaîne pré-auth PaperCut NG/MF, au KEV depuis le 31 août

- **CVE-2026-81578** (CVSS 8,8) : authentification manquante sur une fonction critique — un attaquant non authentifié modifie certains paramètres de configuration.
- **CVE-2026-82078** (CVSS 9,4) : *unsafe reflection* (CWE-470) — les paramètres manipulés font invoquer du bytecode Java déjà présent sur le classpath.
- **Chaînage = RCE pré-auth** : 81578 écrit la cible, 82078 la charge. Aucun upload de code n'est nécessaire.
- **Exploitation confirmée** : Huntress a observé l'exploitation chez deux clients puis reproduit toute la chaîne sur une installation propre non patchée.
- **Divulgation le 27 août, KEV le 31** : quatre jours entre l'annonce et l'inscription au catalogue.
