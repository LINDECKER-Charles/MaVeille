# Tech — Synthèse du mercredi 8 juillet 2026

## Digest court

Deux histoires de sécurité pour devs cette semaine. Côté infra, **BeyondTrust** corrige deux bypass d'authentification pré-auth (CVSS 9.2, CVE-2026-40138/40139) dans ses appliances d'accès distant **RS** et **PRA** — la « clé du royaume » d'un SI, et une cible étatique récurrente. Côté poste de travail, la campagne **ChocoPoC** planque un RAT non pas dans le code PoC visible, mais dans le `requirements.txt` de faux dépôts d'exploit GitHub : un simple `pip install` suffit à te faire voler mots de passe et cookies. Deux rappels : patche tes appliances, et isole tout ce que tu exécutes.

## Top 2 — Accès distant & supply chain dev

- **BeyondTrust RS/PRA** : bypass d'auth pré-auth (CVSS 9.2). Toutes versions ≤ **25.3.2** vulnérables → passe en **25.3.3**, restreins l'admin au réseau de confiance.
- **ChocoPoC** : faux PoC GitHub, malware dans les dépendances (`frint`, `skytext`), C2 via l'API Mapbox. Isole tes tests dans un conteneur sans réseau.
- **À faire** : patch appliances d'accès distant ; ne `pip install` jamais un PoC hors bac à sable.
