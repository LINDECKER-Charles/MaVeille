# IA — Synthèse du samedi 22 août 2026

## Digest court

Trois publications du 21 août tapent toutes sur le même clou : le score ne mesure pas ce qu'on croit. Hugging Face et Hume AI publient une étude qui montre que plusieurs modèles ASR open source reproduisent les erreurs de transcription des benchmarks au lieu de transcrire l'audio — et qu'ils changent de comportement selon des indices acoustiques qui trahissent le jeu de test. NVIDIA, de son côté, fait passer Claude Opus 5 de 30,2 % à 100 % sur ARC-AGI-3 sans toucher au modèle, juste en l'enveloppant dans son harnais AVO. Et un nouveau benchmark de refactoring multilingue, SWE-Bench ProMax, plafonne les meilleurs agents à 41,2 % de résolution. Évaluer un modèle, évaluer un agent et évaluer un benchmark sont trois exercices différents.

## Top 1 — Benchmark optimization en ASR : les modèles reconnaissent le test

- **11 modèles testés** : plusieurs reproduisent le transcript de référence même quand l'audio le contredit.
- **6 sur 11** omettent un « Thank you » clairement audible sur un clip VoxPopuli, parce que la référence l'omet.
- **30-40 %** : taux de récupération de nombres physiquement effacés de l'audio, chez les modèles les mieux classés sur LibriSpeech.
- **~90 %** de switch rate orthographique : certains modèles choisissent « Mr. » ou « Mister » selon le dataset d'origine.
- **Onglet « Benchmark fitting »** ajouté à l'Open ASR Leaderboard, scripts open source.

## Top 2 — NVIDIA AVO : 100 % sur ARC-AGI-3 sans changer de modèle

- **30,2 % → 100,00 RHAE** : Claude Opus 5 seul, puis le même modèle dans le système AVO, sur les 25 environnements et 183 niveaux du set public.
- **Deux mécanismes** : mémoire persistante (l'état survit au-delà de la fenêtre de contexte) et superviseur programmatique qui intervient quand la progression stagne.
- **Transfert** : la même architecture venait de l'optimisation de kernels GPU — interfaces différentes, boucle identique.
- **Périmètre** : set public uniquement, pas les sets semi-privés ni privés.

## Top 3 — SWE-Bench ProMax : le refactoring reste non saturé

- **41,2 %** de resolve rate pour le meilleur modèle, sur 170 instances issues de vrais commits.
- **7 langages** : Python, Java, TypeScript, Go, C, C++, Rust.
- **~60 %** des instances non résolues de SWE-bench Verified contiendraient des tests défectueux, d'après l'audit cité.
