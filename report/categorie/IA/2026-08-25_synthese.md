# IA — Synthèse du mardi 25 août 2026

## Digest court

Deux sujets, deux façons de te rappeler que l'infrastructure compte autant que le modèle. Ox Alpha, le modèle anonyme apparu sur OpenRouter le 20 août, a déclenché une chasse au fingerprinting côté communauté — mais la vraie question, soulevée hier par The New Stack, n'est pas qui l'a entraîné : c'est quelle entité juridique reçoit ton code et sous quels termes, qui diffèrent selon la route empruntée. Côté runtime local, Ollama v0.33.0 corrige un bug de points de restauration de prefill qui faisait retraiter 47 000 tokens à partir de zéro sur une simple annulation, et désactive un message système de Claude Code qui invalidait le cache KV à chaque requête.

## Top 1 — Ox Alpha : le fingerprinting est plus rigoureux que les conditions d'usage

- **`modelprint`** : neuf sondes d'infrastructure, six correspondances sur neuf avec GLM-5.3 — preuve d'infrastructure partagée, pas d'identité de modèle.
- **Termes contradictoires** : la page du modèle annonce « retenu mais pas entraîné dessus », l'EULA Stealth incorporée dit l'inverse.
- **Benchmarks fragiles** : 80 % sur 10 tâches DeepSWE en viral, 58,4 % sur un run reproductible de 113 tâches.

## Top 2 — Ollama v0.33.0 : le cache de prefill redevient fiable

- **Points de restauration garantis** : un prefill annulé conserve tous les points franchis, la reprise repart où elle s'était arrêtée.
- **Bug corrigé** : sur les modèles à couches récurrentes, une requête matchant 46 k tokens sur 47 k repartait de zéro.
- **Message « tokens left » de Claude Code désactivé** : placé en tête de prompt, il cassait le cache KV à chaque appel.
