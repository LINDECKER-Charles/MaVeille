# CSharp — Synthèse du samedi 12 septembre 2026

## Digest court

.NET 11 entre dans sa phase finale. La **Release Candidate 1**, publiée le 8 septembre, arrive avec une **licence go-live** : tu peux la mettre en production et être supporté, avant même la GA. Côté langage, C# 15 **stabilise les types union** — la feature n'est plus en preview. Et deux jours plus tard, l'équipe ASP.NET Core publie le mode d'emploi qui manquait : comment ces unions et les hiérarchies `closed` traversent réellement **System.Text.Json**, les Minimal API, MVC, SignalR et Blazor. La réponse est plus subtile qu'attendu : une union se sérialise **sans discriminateur**, ce qui est un atout côté écriture et un piège côté lecture. À l'inverse, une hiérarchie `closed` peut laisser STJ **inférer** ses types dérivés au lieu de les enregistrer un par un.

## Top 1 — .NET 11 RC1 : la licence go-live, et ce qui se stabilise

- **Licence go-live** : support en production dès la RC1, avec Visual Studio 2026 Insiders ou VS Code + C# Dev Kit.
- **C# 15 stabilise les unions** et affine le modèle `unsafe` — plus de flag de preview.
- **Validation d'options asynchrone** et sérialisation JSON des nouveaux types numériques côté bibliothèques.
- **Publication de conteneurs reproductible**, avec saut des uploads redondants côté SDK.
- **NuGet** : les mises à jour de paquets vulnérables fonctionnent désormais avec `TreatWarningsAsErrors`.
- **ASP.NET Core** : APIs de rafraîchissement d'authentification SignalR finalisées, OpenAPI reflète les APIs obsolètes.

## Top 2 — Unions et hiérarchies `closed` dans ASP.NET Core

- **`public union IntOrString(int, string);`** — un type nommé pour un ensemble fermé de cas, primitifs inclus.
- **Aucun discriminateur en JSON** : STJ écrit uniquement le cas actif, sans enveloppe ni `$type`.
- **`JsonUnionTypeStructuralClassifier`** distingue deux cas objet par leurs noms de propriété — au prix d'un scan du payload.
- **`[JsonPolymorphic(InferClosedTypePolymorphism = true)]`** : STJ déduit les types dérivés d'une hiérarchie `closed`.
- **Limite structurelle** : les unions ne fonctionnent pas pour les query strings, route values, en-têtes ni champs de formulaire.
- **Exhaustivité vérifiée** : ajouter un cas déclenche `CS8509` sur tous les `switch` incomplets.
