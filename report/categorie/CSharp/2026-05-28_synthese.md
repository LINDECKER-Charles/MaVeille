# CSharp / .NET — Synthèse du jeudi 28 mai 2026

Cycle .NET 11 actif sur tous les fronts cette semaine. **Preview 4 sortie le 12 mai** : Runtime Async perd son flag de feature et devient utilisable sans ceinture-bretelles, le JIT gagne plusieurs passes d'optimisation (bounds checks, switch folding, branch elimination), EF Core traite désormais les colonnes JSON comme des citoyens de première classe (queries LINQ traduites en `JSON_VALUE`/`JSON_QUERY`), et le SDK ship un template `dotnet new mcpserver` bundled.

En parallèle, Microsoft trace la roadmap **memory safety pour C# 16** : le keyword `unsafe` voit son périmètre s'élargir à toute opération que le compilateur ne peut prouver safe, avec un nouveau style de commentaire SAFETY inspiré de Rust et un `dotnet format` fixer pour migrer mécaniquement les codebases. Côté agents, le **Agent Governance Toolkit MCP Extensions for .NET** apporte policy engine, audit OpenTelemetry et rate limiting prêts à l'emploi pour les serveurs MCP en C#.

Enfin, NuGet Package Pruning améliore la propreté du graphe de dépendances et rend les reports de vulnérabilités actionnables (tu vois quelle dépendance directe tire la transitive vulnérable).
