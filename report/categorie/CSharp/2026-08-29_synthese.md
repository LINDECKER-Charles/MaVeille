# CSharp — Synthèse du samedi 29 août 2026

## Digest court

Semaine calme côté langage : pas de RC1, la dernière release reste .NET 11 Preview 7 et la GA est calée sur .NET Conf, du 10 au 12 novembre. Deux sujets sortent quand même du lot, tous deux sur le thème « supprimer de la plomberie ». Côté agents, Microsoft publie l'intégration .NET de Foundry Hosted Agents : un package NuGet et trois lignes de C# transforment un `AIAgent` console en endpoint HTTP managé, avec identité Entra, sessions persistées et traces OpenTelemetry câblées d'office. Côté réseau, Preview 7 introduit `SocketsHttpHandler.ShouldEvictConnection`, un callback qui remplace enfin le `PooledConnectionLifetime` aveugle par une décision d'éviction prise connexion par connexion. Les deux sont utilisables aujourd'hui, avec des réserves nettes : prerelease pour l'un, API expérimentale pour l'autre.

## Top 1 — `AgentHost` : de `dotnet run` à un agent hébergé en 3 lignes

- **`Microsoft.Agents.AI.Foundry.Hosting`** : un seul package, à installer en `--prerelease` (Hosted Agents est GA, l'intégration .NET non).
- **`AgentHost.CreateBuilder(args)`** : l'équivalent de `WebApplication.CreateBuilder`, préconfiguré health checks, OpenTelemetry et contexte de session.
- **Deux protocoles** : `responses` (compatible OpenAI, historique et streaming gérés par la plateforme) et `invocations` (contrôle HTTP brut).
- **`azd provision` + `azd deploy`** : image conteneur, ACR, Application Insights, identité Entra dédiée créée automatiquement.
- **Compute déprovisionné après 15 min d'inactivité**, état de session restauré à la reprise — pense au cold start dans tes SLA.

## Top 2 — `ShouldEvictConnection` : la fin du recyclage aveugle de connexions HTTP

- **Le problème** : quand le DNS de l'hôte cible bascule, `HttpClient` continue de taper l'ancienne IP tant que la connexion TCP vit.
- **Le contournement historique** : `PooledConnectionLifetime`, qui tue périodiquement **toutes** les connexions, y compris les saines — et repaie handshake TCP + TLS.
- **Le nouveau levier** : un callback async par connexion, avec `Age`, `ConnectionId`, `DnsEndPoint`, `RemoteEndPoint` et `HttpVersion` dans son contexte.
- **Pattern canonique** : `PooledConnectionLifetime = Timeout.InfiniteTimeSpan` puis re-résolution DNS dans le callback, éviction seulement si l'IP a disparu.
- **`ConnectionId` sur `HttpRequestMessage`** : le même identifiant que la télémétrie `EventSource`, donc corrélation directe avec tes traces.

À noter aussi dans Preview 7 : les wrappers `GZipCompressedContent`, `BrotliCompressedContent` et `ZstandardCompressedContent`, avec un breaking change sans alias — `WindowLog` devient `WindowLog2`.
