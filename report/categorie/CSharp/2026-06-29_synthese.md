# CSharp — Synthèse du lundi 29 juin 2026

## Digest court

Semaine calme côté runtime — pas de nouvelle preview depuis la 5 — mais deux features SDK de **.NET 11 Preview 5** méritent un vrai mini-cours, car elles changent ton outillage quotidien. D'abord, `dotnet new mcpserver` est désormais **bundlé dans le SDK** : tu scaffoldes un serveur MCP sans installer de template, et tu exposes ton métier .NET à un agent IA en quelques lignes. Ensuite, les **apps mono-fichier** gagnent la directive `#:ref` : un `dotnet run app.cs` peut enfin se découper en plusieurs fichiers, sans `.csproj`. De quoi industrialiser tes scripts et tes POC.

## Top 2 — Outillage SDK .NET 11 Preview 5

- **`dotnet new mcpserver`** : template MCP intégré au SDK ; serveur stdio/HTTP, outils via `[McpServerTool]`, publication conteneur.
- **Directive `#:ref`** : les file-based apps référencent d'autres fichiers `.cs` (transitivité incluse) ; `dotnet package add app.cs` opère sur le projet virtuel.
- **À noter** : `System.Net.Http.Json` est implicite dans les apps console `net11.0`, et les checks de vulnérabilité/EOL du SDK sont activables au build (`<CheckSdkVulnerabilities>`).
