# CSharp — Synthèse du lundi 7 septembre 2026

## Digest court

Rien de neuf côté runtime : le blog .NET n'a rien publié depuis le 3 septembre, et .NET 11 reste en Preview 7 avec une GA visée au 10 novembre. L'actualité de la semaine est donc côté outillage et agents. GitHub Copilot code review débarque sur Azure Repos pour tous les clients Azure DevOps, sans inscription préalable — Microsoft admettant au passage que beaucoup d'équipes ne migreront pas vers GitHub de sitôt. Le détail qui compte est la facturation : à l'usage, avec 48 h de latence de reporting et des budgets qui **notifient sans bloquer**. En parallèle, Microsoft Agent Framework livre sa 1.20.0 pour .NET, dont un correctif qui honore enfin l'annulation sur les réponses de workflow hébergées par Foundry — bon prétexte pour reprendre la propagation de `CancellationToken` de bout en bout.

## Top 1 — Copilot code review sur Azure Repos : lis la facture avant d'activer

- **Public preview ouverte à tous** les clients Azure DevOps, sans sign-up depuis le 4 septembre.
- **Facturation par revue** en crédits GitHub AI (1 crédit = 1 cent), visible dans Cost Management **48 h après**.
- **Les budgets ne bloquent rien** : ils notifient. Une policy de revue automatique tourne deux jours avant d'apparaître au coût.
- **Concurrence plafonnée** : 5 revues simultanées par organisation, 2 par utilisateur, 1 par pull request.

## Top 2 — Agent Framework .NET 1.20.0 : l'annulation traverse enfin le workflow hébergé

- **Correctif d'annulation** sur les réponses de workflow hébergées Foundry — le `CancellationToken` n'était pas honoré.
- Améliorations sur la **recherche web**, la gestion des **logprobs**, et la fiabilité **Foundry / Cosmos DB**.
- Rappel utile : un token non propagé transforme chaque timeout client en tokens facturés côté serveur.

## Top 3 — Échéances à ne pas rater

- **.NET 11 GA le 10 novembre 2026**, support STS jusqu'au 9 novembre 2028. Preview 7 est la dernière préversion publiée.
- **NuGet.org** : les anciennes clés API longue durée expirent le **1er novembre**.
