# CSharp — Synthèse du samedi 26 septembre 2026

## Digest court

Semaine calme sur les breaking changes .NET 11 / EF Core, mais Microsoft comble un vrai manque : un SDK .NET officiel pour AG-UI, le protocole qui standardise la communication agent-vers-interface. Développé avec CopilotKit, il s'appuie sur `IChatClient` (`Microsoft.Extensions.AI`) pour transformer n'importe quel backend de chat ou d'agent existant en flux d'événements AG-UI consommable en Server-Sent Events, sans réinventer de format JSON maison.

## Top 1 — AG-UI .NET SDK

- **5 packages NuGet** : `AGUI.Abstractions`, `AGUI.Formatting` (SSE), `AGUI.Protobuf` (optionnel), `AGUI.Client`, `AGUI.Server`.
- **Point d'intégration** : `IChatClient` → `AsAGUIEventStreamAsync()` → flux SSE typé, sans changer ton backend existant.
- **Cas d'usage** : brancher Semantic Kernel, Microsoft Agent Framework ou un simple wrapper Azure OpenAI derrière une UI CopilotKit ou tout client AG-UI.
