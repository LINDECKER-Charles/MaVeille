# Digest Tech — Recap global du jeudi 11 juin 2026

Six sujets retenus sur trois thématiques actives (Tech, CSharp, IA), Angular restant calme. La journée est dominée par la sécurité au lendemain d'un Patch Tuesday record (~208 CVE) : SAP corrige une faille SAML à 9.9 et Microsoft une vulnérabilité Windows wormable. En parallèle, .NET pousse son servicing de juin et EF Core ouvre la recherche vectorielle, tandis que l'IA open-weights reste atone face aux sorties propriétaires (Claude Fable 5, Gemini 3.5 Live Translate).

## Sécurité

Deux failles critiques fraîches. **SAP CVE-2026-44748** (CVSS 9.9) est un XML Signature Wrapping sur SAML NetWeaver touchant `SAP_BASIS` 702–919 — une classe d'attaque ancienne qui ressurgit quand la signature XML n'est pas validée sur le document complet. **Windows CVE-2026-45657** présente le profil wormable redouté (Network / Authentication None / User Interaction None) sur Windows 11 et Server. Les deux exigent un patch prioritaire sur les hôtes exposés.

## .NET & données

Le **servicing .NET de juin** rejoue les correctifs de sécurité sur les branches 8/9/10 : rebuild et repull des images Docker requis, un simple recompile ne suffit pas. Plus structurant, **EF Core** traduit désormais la recherche par plus proche voisin approximatif vers SQL Server 2025 (`VectorSearch()`, `WithApproximate()` → `WITH APPROXIMATE`) et traite les colonnes JSON en première classe — à comparer à ton réflexe pgvector.

## IA

Côté poids ouverts, rien de neuf entre le 9 et le 11 juin. L'actualité est propriétaire : **Claude Fable 5** (contexte 1M, 128k de sortie, dispo Bedrock/Vertex/Foundry, fallback sécurité vers Opus 4.8, rétention 30 j) et **Gemini 3.5 Live Translate** (traduction vocale temps réel).

## À retenir si tu n'as qu'une minute

- Patche **SAP NetWeaver** (CVE-2026-44748, SAML) et **Windows** (CVE-2026-45657, wormable) sans attendre.
- Mets à jour tes **runtimes .NET** et repull les images de base après le servicing de juin.
- **EF Core** sait faire du vector search sur SQL Server 2025 — utile pour le RAG, mais compare à pgvector avant de t'engager.
- IA : **Fable 5** dispo partout, mais Covered Model (rétention 30 j, pas de zero-data-retention).
