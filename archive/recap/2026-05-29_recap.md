## Sécurité

Une journée chargée pour les équipes responsables des dépendances. **PostgreSQL 18.4** (et les branches 17.10, 16.14, 15.18, 14.23) corrige 11 vulnérabilités, dont une **fuite de timing MD5** qui rend cassable l'authentification password en clair (les déploiements scram-sha-256, défaut depuis longtemps, sont épargnés) et une **injection SQL via `ALTER SUBSCRIPTION ... REFRESH PUBLICATION`** qui touche la réplication logique. La CISA ajoute simultanément **CVE-2026-45321 (TanStack, CVSS 9.5)**, **Nx Console** et **DAEMON Tools** à son catalogue Known Exploited Vulnerabilities — 84 versions npm publiées sous l'identité légitime de TanStack via vol d'OIDC token. Et **bzip2 < 1.0.9** corrige un off-by-one dans `bzip2recover` (CVE-2026-42250) — Linux distros vont republier.

## Écosystème .NET

`.NET 11 Preview 4` continue son rythme mensuel. **EF Core 11** ouvre la voie au **vector search natif SQL Server 2025** avec `VectorSearch()` et `WithApproximate()`, élève les colonnes JSON au rang de citoyens de première classe dans le modèle relationnel, et offre `ChangeTracker.GetEntriesForState()` qui n'exige plus de `DetectChanges()` préalable — gain net pour les contextes long-vivants. Côté ASP.NET Core, le composant **`Virtualize`** cesse de sauter quand un item au-dessus du viewport change de taille (nouveau paramètre `AnchorMode` pour chat / feeds / logs), le `mcpserver` template entre dans le SDK par défaut, et un nouveau template `blazor-wasm-servicedefaults` câble OpenTelemetry + service discovery + resilience HTTP via Aspire.

## IA open source

L'écosystème **diffusion language models** prend de l'épaisseur. **LLaDA2 (InclusionAI / Ant Group)** scale le pari à **100B paramètres** : génération par raffinement itératif blocs masqués → unmasking par confiance, avec versions FP8 quantizées disponibles sur HF/ModelScope. La librairie `diffusers` absorbe en parallèle une **vague de nouveaux pipelines** — LLaDA2, NucleusMoE-Image (2B actifs / 17B totaux, MoE sparse pour text-to-image), ERNIE-Image, LongCat-AudioDiT, ACE-Step — plus l'arrivée du decoder et inpaint pour FLUX.2.

## Marché / Tooling

Le **Stack Overflow Developer Survey 2026** confirme la bascule du marché des assistants IA : **GitHub Copilot tombe à 51 %** (vs 67 % l'an passé), **Cursor débute à 18 %**, **Claude Code à 10 %**. Cursor atteint **$2B ARR en moins de 24 mois** — record absolu B2B SaaS.

## À retenir si tu n'as qu'une minute

- **Patch immédiat PostgreSQL** si tu héberges du Postgres : 11 CVE, dont fuite de timing MD5 (downgrade vers scram-sha-256 si pas déjà fait) et SQL injection logical replication.
- **Audit ton `package.json`** pour TanStack/Nx Console — CISA confirme exploitation active, supply chain npm via OIDC token theft.
- **EF Core 11 P4** te donne du `GetEntriesForState()` sans `DetectChanges()` — gain net sur contextes long-vivants (services BG, agents).
- **LLaDA2 100B en FP8** disponible si tu testes des architectures diffusion pour génération texte côté inférence locale.
