# Digest Tech — Recap global du jeudi 28 mai 2026

**14 sujets retenus aujourd'hui sur 4 thématiques.** Trois mouvements de fond traversent la journée : la **bascule des plateformes vers les paiements agentiques** (Visa + Replit), la **maturation des architectures d'inférence LLM** (NVIDIA diffusion + ITBench-AA), et la **convergence memory-safety / preuves formelles** côté outillage développeur (C# 16 + Creusot Rust).

## Frameworks web et backend

**Angular 22 est officiellement stable depuis le 20 mai 2026** — la news la plus structurante n'est pas tant les features framework (Signal Forms stables, zoneless par défaut, Selectorless Components) que **l'intégration native du Model Context Protocol** dans l'outillage officiel via `ng add @angular/mcp`. Une fois activé, ton IDE peut interroger l'arbre de composants et générer du code Angular contextualisé à la version exacte du projet. Vitest devient aussi le test runner par défaut. Côté .NET, **.NET 11 Preview 4** (12 mai) sort Runtime Async de sa cage de preview-flag et apporte des optimisations JIT sérieuses (bounds check elimination, switch folding, branch elimination). EF Core traite désormais les colonnes JSON comme des citoyens de première classe avec traduction LINQ native. Le SDK contient un template `dotnet new mcpserver` bundled. En parallèle, Microsoft trace la **roadmap memory safety pour C# 16** : le keyword `unsafe` voit son périmètre s'élargir à toute opération que le compilateur ne peut prouver safe, avec un fixer `dotnet format` pour migrer mécaniquement les codebases. Un nouveau **Agent Governance Toolkit MCP Extensions for .NET** apporte policy engine YAML, audit OpenTelemetry et rate limiting pour les serveurs MCP en C#.

## IA open source

Quatre angles cette semaine. **ITBench-AA** (IBM Research + Artificial Analysis) est le premier benchmark d'agents enterprise IT à résister aux frontier models : Claude Opus 4.7 plafonne à **47%**, GPT-5.5 à **46%**, sur du diagnostic d'incidents Kubernetes. Plus surprenant : plus d'investigation ne sauve pas, et **Gemma 4 31B atteint 37% à 0,14 $/tâche** vs ~5 $/tâche pour les frontier. Côté architectures, **NVIDIA Nemotron-Labs Diffusion** est le premier modèle qui réunit AR, diffusion et self-speculation dans une seule famille (3B/8B/14B), avec **4× le throughput de Qwen 3-8B sur SPEED-Bench** à accuracy comparable. Pour les déploiements vLLM à haut volume, l'expérimentation vaut le coup. **Reachy Mini passe en full local** avec une stack reference VAD (Silero) + STT (Parakeet-TDT) + LLM (Gemma 4) + TTS (Qwen3-TTS) exposée via un endpoint compatible OpenAI Realtime API — latence ~800 ms - 1,2 s, zero cloud, archi reproductible pour tout assistant vocal. Enfin, **TRL Delta Weight Sync via Hub Bucket** ramène la sync de modèles 1T paramètres en RLHF de 25 minutes à 45 secondes par step — niche mais signal d'infrastructure MLOps mature.

## Sécurité et tech overview

L'événement majeur de la journée : **Visa investit dans Replit** et intègre Visa Intelligent Commerce + Trusted Agent Protocol nativement dans la plateforme. Les agents construits sur Replit peuvent désormais initier et accepter des paiements Visa sans onboarding marchand. Trusted Agent Protocol = OAuth pour agents côté paiement, candidat sérieux à devenir standard de fait. En parallèle, Replit ouvre des contrats jusqu'à 200 K $ self-serve — signal d'industrialisation du « vibe coding » enterprise. Côté outillage developer, **Creusot** (verificateur déductif Rust) atteint la tête de Hacker News : preuves formelles désormais à portée de dev « normaux », convergence claire avec C# 16 memory safety vue côté Microsoft. Tension communautaire autour d'**AMD qui supprime la licence Vivado WebPACK gratuite sur Linux** — encore un pivot vendor-first qui accélère la migration vers OpenROAD/Yosys/nextpnr. Et une étude Lenz Research montre que les frontier LLMs **divergent sur 37% des fact-checks sensibles, 9% sur le factuel pur** — best-of-N + vote majoritaire gagne 8 points d'accuracy, pattern à intégrer si tu construis un produit fact-checking.

## À retenir si tu n'as qu'une minute

Trois actions concrètes pour aujourd'hui :

1. **Installer le serveur MCP Angular officiel** dans ton workflow IDE — `ng add @angular/mcp` — gain immédiat en qualité des suggestions de code Angular dans Cursor/Claude Code/Copilot.
2. **Lancer `dotnet list package --vulnerable` sur tes solutions critiques** pour tester le nouveau NuGet Package Pruning ; tu verras quelle dépendance directe tire les transitives vulnérables.
3. **Surveiller le Trusted Agent Protocol de Visa** si tu construis un produit avec une couche agent qui doit transacter — ça va devenir un standard structurant des prochains 12-24 mois.
