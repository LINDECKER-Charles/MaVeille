# Digest Tech — Recap global du samedi 6 juin 2026

Samedi calme en volume, mais dense en qualité : 7 sujets sur 4 catégories, avec deux fils conducteurs forts. Premier fil : la semaine post-GA d'Angular 22 produit ses premiers guides de migration communautaires, et VS Code 1.123 marque un saut qualitatif dans l'outillage IA des développeurs. Second fil : la sécurité réseau est sous tension — un 7e zero-day Cisco SD-WAN sans patch et le forecast du Patch Tuesday de juin exposent une fenêtre de risque critique autour du 26 juin.

## Angular

Une semaine après le GA d'Angular 22, la communauté publie ses premiers retours de migration. Le point crucial : le passage à OnPush par défaut ne s'applique qu'aux **nouvelles applications** générées via la CLI, pas aux projets existants. En revanche, le passage à TypeScript 6 est une rupture universelle — tout projet Angular doit migrer son toolchain avant de monter en v22.

## CSharp / .NET

VS Code 1.123 (sorti le 3 juin) apporte une refonte de l'expérience agent : sessions parallèles, contexte 1 million de tokens, synchronisation cross-machines, et surtout un mode BYOK (Bring Your Own Key) sans inscription GitHub — utile pour les environnements air-gapped ou les organisations avec des contraintes de SSO strictes.

## IA Open Source

Trois sorties notables cette semaine. H Company publie Holo3.1, une famille complète de modèles computer-use open-weight (0.8B à 35B) avec quantification FP8/NVFP4/GGUF prête pour le local. Microsoft sort ses premiers LLMs propres (MAI-Code-1-Flash et MAI-Thinking-1) depuis le Build 2026, marquant une stratégie de diversification loin d'OpenAI.

## Sécurité / Tech

Cisco confirme un 7e zero-day SD-WAN exploité en 2026, CVE-2026-20245, sans patch disponible. L'exploitation requiert des credentials netadmin (souvent disponibles via les failles précédentes de la série). Parallèlement, le forecast du Patch Tuesday de juin (prévu le 9 juin) pointe une deadline Secure Boot critique au 26 juin et un Exchange RCE (CVE-2026-42897) déjà exploité.

## À retenir si tu n'as qu'une minute

- **Angular 22 + TypeScript 6** : migration obligatoire du toolchain pour tous les projets, OnPush uniquement pour les nouveaux.
- **VS Code 1.123** : teste le mode multi-agents et le BYOK si tu travailles en environnement restreint.
- **Cisco SD-WAN** : si tu as des équipements SD-WAN, audite les credentials netadmin — pas de patch, surveille les IoC Mandiant.
- **Patch Tuesday 9 juin** : déploie le correctif Exchange CVE-2026-42897 dès sa sortie, et finalis le Secure Boot avant le 26 juin.
