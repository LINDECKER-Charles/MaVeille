# Digest Tech — Recap global du mercredi 10 juin 2026

Sept sujets aujourd'hui sur trois thématiques actives, plus une journée calme côté Angular. La séquence est dominée par deux mouvements : Microsoft fait avancer .NET 11 vers la stabilité (Preview 5, le 9 juin) avec des nouveautés de langage majeures, et la fenêtre sécurité reste brûlante (zero-day Chrome exploité, Patch Tuesday record, RCE critique Veeam). En toile de fond, les modèles de code open-weight pour exécution locale continuent de tomber, Cohere et JetBrains visant le self-hosting.

## Frameworks & plateformes

**.NET 11 Preview 5** arrive le 9 juin et muscle le langage : `closed` hierarchies, *union types* et *union patterns*, plus une refonte du `unsafe`. Côté données, EF Core bascule la **compatibilité SQL Server 2022 par défaut** et introduit l'alerte **EF1004** quand une requête async tourne en synchrone. Le SDK ajoute des checks de vulnérabilité et d'EOL **au build**, et `dotnet new` embarque un template MCP Server.

## Sécurité

Trois fronts chauds le même jour. Google corrige **CVE-2026-11645**, un zero-day V8 exploité (5ᵉ de l'année). Microsoft publie un **Patch Tuesday record** (≈ 208 CVE, 3 zero-days, dont CVE-2026-41091 Defender exploitée et un RCE noyau TCP/IP CVSS 9.8). Veeam patche **CVE-2026-44963**, RCE critique (CVSS 9.4) exploitable par tout compte de domaine sur un Backup Server joint au domaine.

## IA open source

Les modèles de code open-weight visent le poste local. **North Mini Code 1.0** (Cohere, 9 juin) est un MoE 30B/3B sous Apache 2.0 qui tient sur un seul H100. **Mellum2** (JetBrains, 12B/2.5B) débarque massivement en GGUF pour llama.cpp et Ollama, en variantes instruct et thinking.

## À retenir si tu n'as qu'une minute

- **Patch en urgence** : Chrome ≥ 149.0.7827.103, Veeam B&R 12.3.2.4854, et applique le Patch Tuesday Windows (RCE noyau CVSS 9.8).
- **Teste .NET 11 Preview 5** sur une branche : union types et `closed` hierarchies changent ta façon de modéliser un domaine.
- **EF1004** : prépare-toi à voir l'alerte si tu as des `.ToList()` sur des requêtes pensées async.
- **Coding local** : North Mini Code et Mellum2 self-hostables, utiles pour du RAG/sous-agents sans API externe.
