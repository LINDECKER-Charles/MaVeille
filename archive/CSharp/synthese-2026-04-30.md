# Synthèse Veille C# / .NET / ASP.NET — 30 avril 2026

> Couverture des dernières 24 heures (28-30 avril 2026)

## En bref

La semaine est dominée par la **mise à jour d'urgence de sécurité .NET 10.0.7 (CVE-2026-40372)** publiée le 21 avril, qui reste un sujet d'actualité critique pour toutes les applications ASP.NET Core. Côté nouveautés, Microsoft pousse fortement l'angle **IA et agents** avec l'**Agent Governance Toolkit** pour gouverner les appels d'outils MCP en .NET. Côté graphique, **SkiaSharp 4.0 Preview 1** sort enfin après deux ans, avec **Uno Platform comme co-mainteneur**. Visual Studio 2026 continue son cycle d'updates avec l'intégration des **agents cloud GitHub Copilot**.

## Top 5 à retenir

1. **Sécurité critique ASP.NET Core (CVE-2026-40372)** — Faille HMAC dans `Microsoft.AspNetCore.DataProtection` (CVSS 9.1) permettant la forgerie de cookies d'authentification. Patch obligatoire vers **.NET 10.0.7**.
2. **Agent Governance Toolkit pour .NET** — Nouvelle suite open source pour gouverner les appels MCP : contrôle de politiques, scan de sécurité, sanitisation des réponses. Couvre les 10 risques OWASP Agentic.
3. **SkiaSharp 4.0 Preview 1** — Première release majeure depuis presque 2 ans (Skia milestone 147). Uno Platform devient co-mainteneur officiel aux côtés de Microsoft.
4. **Visual Studio 2026 v18.5** — IntelliSense reprend la priorité face à Copilot, intégration des agents cloud GitHub Copilot pour offloader les tâches sur infrastructure distante.
5. **Fin de support ASP.NET Core 2.3 sur .NET Framework** annoncée pour le **7 avril 2027**. Migration recommandée vers ASP.NET Core sur .NET 10.

## Action recommandée

Vérifier immédiatement les déploiements ASP.NET Core en production : si vous utilisez `Microsoft.AspNetCore.DataProtection` 10.0.0 → 10.0.6, mettez à jour vers **10.0.7**, recompilez et redéployez. La vulnérabilité permet l'élévation de privilèges via cookies forgés.
