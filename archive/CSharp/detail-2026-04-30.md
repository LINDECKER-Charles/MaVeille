## 1. Sécurité — CVE-2026-40372 : faille critique dans ASP.NET Core Data Protection

### Description

Microsoft a publié le **21 avril 2026** une mise à jour de sécurité hors-bande (out-of-band) pour corriger une vulnérabilité critique dans ASP.NET Core, identifiée sous **CVE-2026-40372**, classée avec un **score CVSS de 9.1**.

### Cause technique

Dans les versions **10.0.0 à 10.0.6** du package NuGet `Microsoft.AspNetCore.DataProtection`, le chiffreur authentifié géré pouvait calculer son tag de validation HMAC sur les mauvais octets de la charge utile, puis ignorer le hash calculé. Conséquence : une régression dans la vérification cryptographique permet à un attaquant de forger des charges utiles qui passent les contrôles d'authenticité de Data Protection.

### Surfaces d'attaque concernées

- Cookies d'authentification
- Tokens antiforgery
- TempData
- État OIDC (OpenID Connect)

Un attaquant non authentifié peut potentiellement obtenir des privilèges **SYSTEM** sur les systèmes affectés en forgeant des cookies d'authentification.

### Remédiation

- Mettre à jour `Microsoft.AspNetCore.DataProtection` vers la version **10.0.7 ou supérieure**
- **Recompiler et redéployer** toutes les applications qui embarquent cette bibliothèque
- Pour les applications hébergées avec runtime partagé : installer la mise à jour .NET 10.0.7

## 2. IA & MCP — Agent Governance Toolkit pour .NET

### Annonce

Le **29 avril 2026**, Jack Batzner publie sur le blog .NET un article expliquant comment gouverner les appels d'outils MCP (Model Context Protocol) en .NET avec l'**Agent Governance Toolkit (AGT)**, suite open source de Microsoft initialement publiée le 2 avril 2026 sous licence MIT.

### Contexte

Les agents IA se connectent à de vrais outils — lecture de fichiers, appels d'API, requêtes en base — via MCP. Cela introduit des risques de sécurité considérables : exécution non contrôlée, prompt injection, exfiltration de données, escalade de privilèges via outils mal définis.

### Composants clés (côté .NET)

- **McpGateway** — pipeline gouverné qui évalue chaque appel d'outil avant exécution (politiques, sandbox, autorisations).
- **McpSecurityScanner** — détection de définitions d'outils suspectes avant exposition au LLM.
- **McpResponseSanitizer** — supprime les motifs de prompt injection, identifiants exposés et URL d'exfiltration dans les sorties d'outils.

### Caractéristiques techniques

- Paquet `.NET` ciblant **.NET 8.0+**
- Une seule dépendance directe : `YamlDotNet`
- Disponible aussi en Python, TypeScript, Rust et Go
- Première suite open source couvrant l'intégralité du **OWASP Agentic Top 10**
- Plus de **9 500 tests** dans la base
- Fuzzing continu avec ClusterFuzzLite, provenance SLSA, OpenSSF Scorecard, scan CodeQL

### Pourquoi c'est important

C'est le premier framework officiel Microsoft qui pose un **plan de contrôle déterministe** pour les agents .NET, avec une enforcement de politiques en sub-milliseconde. Pour les équipes qui construisent des agents IA en .NET, cela devient une référence à évaluer avant production.

## 3. Graphique — SkiaSharp 4.0 Preview 1

### Annonce

Le **28 avril 2026**, David Ortinau annonce sur le blog .NET la sortie de **SkiaSharp 4.0 Preview 1**, première release majeure depuis presque deux ans.

### Contenu de la release

SkiaSharp 4.0 embarque **Skia milestone 147**, soit **2 ans et demi et 28 milestones** d'améliorations en termes de rendu, qualité et sécurité côté upstream.

Améliorations notables :

- **Images downscalées plus nettes** — sharpening de mipmap activé par défaut
- **Orientation automatique des photos** — les codecs respectent désormais les métadonnées Exif
- **Gestion améliorée des grandes images** — les bitmaps oversized se découpent automatiquement en tuiles pour respecter les limites de texture GPU

### Partenariat avec Uno Platform

**Uno Platform** devient officiellement **co-mainteneur** de SkiaSharp aux côtés de l'équipe .NET. Objectif annoncé : maintenir un rendu graphique cross-platform accessible à tous les développeurs .NET avec une cadence de release plus prévisible.

### Événement à venir

Un événement « Focus on SkiaSharp » est prévu en ligne par Uno Platform le **30 juin 2026** pour célébrer la collaboration et la sortie GA.

## 6. Visual Studio 2026 — Updates récents

### Sécurité

Une **mise à jour de sécurité KB5072533** pour Visual Studio 2026 version **18.5.2** a été publiée, avec modifications de contenu publiées le **29 avril 2026**.

### Nouvelles fonctionnalités (April Update 18.5.0)

#### IntelliSense reprend la priorité

Avec Visual Studio 2026 April Update 18.5.0, **IntelliSense reprend la priorité sur les complétions Copilot**. L'éditeur priorise désormais la liste IntelliSense et n'affiche qu'une seule suggestion à la fois, mettant fin à un conflit d'UX qui durait depuis plusieurs mois.

#### Cloud Agents GitHub Copilot

L'update d'avril intègre les **agents cloud** dans GitHub Copilot. Les développeurs peuvent désormais offloader des tâches sur une infrastructure distante pour une exécution scalable et isolée. Les sessions d'agents cloud peuvent être démarrées directement depuis Visual Studio via le sélecteur d'agent dans la fenêtre Chat.

#### Autres améliorations

- L'éditeur JSON supporte les spécifications JSON Schema plus récentes
- Les agents Copilot peuvent désormais découvrir et utiliser automatiquement les **skills** définies dans un repo ou un profil utilisateur

### Versions récentes

- **18.5.0** — April Update (avec cloud agents et IntelliSense priority)
- **18.5.1** — 21 avril 2026
- **18.5.2** — Security update KB5072533 (29 avril 2026)

## 8. Rappel C# 14 et .NET 10 (contexte)

Pour les équipes qui n'ont pas encore migré, rappels des features marquantes :

### C# 14

- **Extension members** — propriétés d'extension, opérateurs d'extension, membres statiques d'extension
- **Field keyword** — accès au backing field caché d'une auto-property dans get/set
- **Null-conditional assignment** — `?.` et `?[]` utilisables à gauche d'une assignation
- **Lambda parameter modifiers** — `scoped`, `ref`, `in`, `out`, `ref readonly` sans typage explicite
- **Conversions implicites** entre arrays, spans et read-only spans
- **`nameof` sur generics non liés** — `nameof(List<>)` retourne `List`

### .NET 10

- LTS : supporté jusqu'au **14 novembre 2028**
- Refresh cumulatif d'avril : **10.0.6** (14 avril) puis **10.0.7** (21 avril, OOB sécurité)
