## 1. Plateforme — Ubuntu 26.04 LTS « Resolute Raccoon » embarque .NET 10

### Annonce

Le **1er mai 2026**, Microsoft publie sur le blog .NET un article confirmant qu'**Ubuntu 26.04 LTS** sort officiellement aujourd'hui avec **.NET 10** intégré dans le dépôt principal. L'annonce parallèle de Canonical sur Ubuntu Community Hub confirme la disponibilité globale.

### Ce qui change concrètement

- **Installation native via APT** : `sudo apt install dotnet-sdk-10.0` fonctionne sans repo Microsoft additionnel.
- **PPA `dotnet-backports`** disponible pour installer **.NET 8 et .NET 9** côte à côte sur la même distribution.
- **Nouvelles images conteneurs `-resolute`** : `mcr.microsoft.com/dotnet/aspnet:10.0-resolute`, `mcr.microsoft.com/dotnet/runtime:10.0-resolute`, etc.
- **Native AOT pleinement supporté** sur Ubuntu 26.04 — un exemple de service web aboutit à un binaire **self-contained de 13 Mo**.
- Support cryptographie post-quantique exposé sur la chaîne complète (OpenSSL 3.4 + .NET 10).

### Cycle de vie

Ubuntu 26.04 LTS est **supportée jusqu'en avril 2031** (5 ans). C'est la combinaison recommandée pour les nouveaux déploiements .NET 10 LTS sur Linux jusqu'à la fin du support .NET 10 (14 novembre 2028).

### Pourquoi c'est important

C'est la première LTS Ubuntu qui ship une version récente de .NET dans son dépôt officiel sans dépendance au repo Microsoft. Cela simplifie les pipelines CI/CD, les images Docker minimales, et les politiques de sécurité côté infra (un dépôt de moins à approuver).

## 2. Sécurité — CVE-2026-40372 : phase rotation des clés Data Protection

### Évolution du sujet

La vulnérabilité CVE-2026-40372 (CVSS 9.1) reste le sujet de sécurité numéro un. Au-delà du patch initial **.NET 10.0.7** publié le 21 avril, plusieurs CSIRT et organismes ont publié cette semaine des **avis de remédiation post-patch** insistant sur la rotation des clés.

### Nouveaux conseils publiés

- **Université York (24 avril)** — Avis officiel pour le secteur académique ; recommande la rotation immédiate du Data Protection key ring après application du patch, et l'invalidation des sessions actives.
- **Security Boulevard** — Récapitulatif complet : la simple mise à jour du paquet ne suffit pas si des cookies forgés ont déjà été émis avant remédiation. Il faut **purger le ring de clés** pour invalider les payloads frauduleux.
- **Penligent (analyse technique)** — Décortique le bug HMAC : le calcul s'effectuait sur les mauvais octets puis le hash était discardé, créant une signature toujours validée comme correcte.

### Checklist de remédiation actualisée

1. Mettre à jour `Microsoft.AspNetCore.DataProtection` ≥ **10.0.7**
2. Recompiler et redéployer toutes les apps ASP.NET Core hébergeant Data Protection
3. **Roter le Data Protection key ring** (`PersistKeysToFileSystem`, `PersistKeysToAzureBlobStorage`, etc.)
4. Forcer la déconnexion de toutes les sessions utilisateur actives
5. Auditer les logs d'authentification 7 jours en arrière à la recherche d'anomalies
6. Vérifier les apps qui utilisent Data Protection pour antiforgery, TempData, ou cookies OIDC

## 3. Outillage — Visual Studio 2026 + Cloud Agent : « Assign a Task, Close the IDE, Get a PR »

### Annonce

Visual Studio Magazine publie le **29 avril 2026** un article détaillé sur l'intégration des **agents cloud GitHub Copilot** dans Visual Studio 2026, qui complète l'expérience déjà disponible dans VS Code.

### Pattern d'usage

- Le développeur décrit une tâche dans Visual Studio (ex. « refactor service X to use IOptions<Y> »).
- L'agent cloud distant prend la tâche en charge, exécute les modifications sur infra Microsoft.
- Le développeur peut **fermer Visual Studio** ; l'exécution se poursuit en arrière-plan.
- À la fin, une **Pull Request est ouverte automatiquement** sur le repo GitHub avec le diff, les tests et un résumé.

### Avantages

- Désynchronisation totale de la machine du développeur
- Tâches longues (refactos volumineux, migrations) non bloquantes
- Isolation totale du code en sandbox cloud (pas de risque sur la machine locale)
- Audit centralisé des actions de l'agent

### Versions concernées

- **Visual Studio 2026 v18.5.0** (April Update, 14 avril) — Première intégration
- **Visual Studio 2026 v18.5.1** (21 avril) — Stabilisation
- **Visual Studio 2026 v18.5.2** (security update KB5072533, 29 avril)

### Considérations entreprise

Pour les équipes enterprise, attention aux quotas Copilot : la facturation à l'usage entrant en vigueur le 1er juin 2026 (cf. section 6) impactera directement les organisations qui adoptent massivement les agents cloud, lesquels consomment potentiellement plus de tokens que les complétions inline traditionnelles.

## 5. .NET 11 Preview 3 — Récapitulatif

### Statut

.NET 11 Preview 3 reste la dernière preview disponible (publiée mi-avril). C'est la 3ᵉ étape vers la GA prévue en **novembre 2026** comme version Standard Term Support (STS).

### Points clés

- **Runtime Async** — Sort de la zone preview-feature, devient activable plus largement. La gestion async passe au niveau du runtime lui-même.
- **JIT** — Nouvelles optimisations pour les méthodes async, meilleure inlining.
- **ASP.NET Core** — Compression **Zstandard** native (alternative plus rapide à Brotli pour les payloads moyens).
- **EF Core** — Améliorations sur le mapping JSON pour Complex Types (1:1 et 1:N).
- **MAUI** — Pin clustering étendu sur Map control (groupement automatique des marqueurs proches).
- **C# 15 (preview)** — Collection expression arguments pour personnaliser les collections à la création.

### Périmètre couvert

Runtime, SDK, libraries, ASP.NET Core, EF Core, .NET MAUI, container images.

## 6. Écosystème — GitHub Copilot vers facturation à l'usage le 1er juin

### Annonce

Visual Studio Magazine confirme que **GitHub Copilot bascule sur un modèle de facturation à l'usage le 1er juin 2026**. L'annonce génère des préoccupations dans la communauté .NET, particulièrement autour des cloud agents et des features IA-natives de Visual Studio 2026.

### Inquiétudes principales

- **Prévisibilité des coûts** — Difficile d'estimer la consommation pour une équipe entière.
- **Accès aux modèles premium** — GPT-5, Claude 4.6 et autres modèles avancés pourraient nécessiter des crédits supplémentaires hors plan inclus.
- **Quotas mensuels** — Les plans Pro et Business gardent leur prix, mais l'inclusion d'usage pourrait diminuer.
- **Cloud agents** — Plus gourmands en tokens que les complétions inline ; impact direct sur la facture.

### Recommandations pour les équipes .NET

- Auditer la consommation actuelle Copilot avant juin
- Établir des politiques internes sur l'utilisation des cloud agents (réservés à certains scénarios)
- Évaluer des alternatives open source (LlamaSharp, Ollama + Phi-4) pour les tâches non sensibles
