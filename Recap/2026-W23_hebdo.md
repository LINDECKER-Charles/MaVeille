# Digest Tech — Récap Semaine W23 (2026-06-01 → 2026-06-07)

La semaine 23 restera celle d'un alignement rare entre les trois piliers de ta veille. Angular 22 passe en GA et stabilise tout l'arsenal « signal-first » (Signal Forms, `httpResource`, Selectorless), avec TypeScript 6 désormais imposé à ton toolchain. Côté IA ouverte, MiniMax M3 devient le premier open-weight à tenir tête aux modèles propriétaires top-tier sur le coding agentique tout en offrant 1M de tokens de contexte. Et la sécurité infra a vécu une semaine sous tension maximale : RCE non authentifiée sur tous les contrôleurs de domaine, attaque supply-chain npm « Miasma », NetScaler et Cisco SD-WAN exploités, le tout à la veille d'un Patch Tuesday chargé.

## 🏆 Top 3 de la semaine

- **Angular 22 en GA (3 juin)** : Signal Forms, `httpResource`/`resource`, Selectorless Components et Angular Aria passent stable, compilateur Rust Oxc à la clé. C'est le jalon qui sort le réactif signal-first des flags expérimentaux — et qui t'oblige à migrer ton toolchain vers TypeScript 6.
- **Netlogon CVE-2026-41089** : exécution de code SYSTEM non authentifiée sur n'importe quel contrôleur de domaine Windows Server 2012→2025, exploitation confirmée in-the-wild. Un seul DC non patché = tout l'AD compromis. La menace la plus grave de la semaine.
- **MiniMax M3** : premier open-weight à battre GPT-5.5 et Gemini 3.1 Pro sur SWE-Bench Pro (59,0 %) avec 1M de contexte et une architecture MSA qui divise par 20 le coût du contexte long. L'open-weight rattrape le frontier coding.

## 📡 Tech Overview — Bilan de la semaine

### Tendance
Semaine de sécurité exceptionnellement chargée : la post-compromission et l'infra critique dominent (DC, VPN, supply-chain), avec en clôture une release base de données majeure.

### Sujets marquants
- **Netlogon CVE-2026-41089** (jeu. 4) : RCE SYSTEM non authentifiée sur tous les contrôleurs de domaine Windows Server 2012→2025, exploitée. Patche tes DC dans la même fenêtre. Source : Help Net Security — https://www.helpnetsecurity.com/2026/06/01/windows-netlogon-rce-exploited-cve-2026-41089/
- **Miasma — supply-chain npm sur 32 paquets Red Hat** (jeu. 4) : ver voleur de credentials déclenché au `npm install`, 96 versions piégées, ~117K downloads/semaine. Audite tes dépendances post-1er juin et fais tourner tes secrets CI. Source : Wiz Blog — https://www.wiz.io/blog/miasma-supply-chain-attack-targeting-redhat-npm-packages
- **NetScaler CVE-2026-3055 & Cisco SD-WAN CVE-2026-20245** (jeu. 4 / sam. 6) : fuite mémoire SAML IDP (CVSS 9.3) en exploitation à grande échelle, et 7e zero-day SD-WAN 2026 exploité sans patch disponible. Sources : Rapid7 — https://www.rapid7.com/blog/post/etr-cve-2026-3055-citrix-netscaler-adc-and-netscaler-gateway-out-of-bounds-read/ ; Help Net Security — https://www.helpnetsecurity.com/2026/06/05/cisco-sd-wan-cve-2026-20245-0-day-exploited/
- **PostgreSQL 19 Beta 1** (dim. 7) : autovacuum parallèle, I/O asynchrone auto-scalé (`io_min_workers`/`io_max_workers`), read-ahead amélioré, inserts plus rapides, `EXPLAIN (ANALYZE, IO)`. GA visée sept./oct. 2026 — le bon moment pour benchmarker tes grosses tables. Source : PostgreSQL — https://www.postgresql.org/about/news/postgresql-19-beta-1-released-3313/
- **GitHub Copilot SDK en GA** (dim. 7) : API agentique embarquable, support MCP natif, sandboxes isolées — à cadrer côté budget depuis la bascule vers les GitHub AI Credits. Source : GitHub Changelog — https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available/
