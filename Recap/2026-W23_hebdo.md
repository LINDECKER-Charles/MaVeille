# Digest Tech — Récap Semaine W23 (2026-06-01 → 2026-06-06)

La semaine 23 marque un tournant à trois niveaux simultanément. Angular 22 passe en GA et redéfinit le workflow dev avec son MCP server stable, forçant toutes les équipes à migrer vers TypeScript 6. L'open-weight franchit un plafond symbolique : MiniMax M3 (59 % SWE-Bench Pro) rivalise désormais avec les modèles propriétaires top-tier sans API fermée. Et la sécurité infra atteint un niveau d'alerte exceptionnel — Netlogon RCE non authentifiée sur tous les DCs, Miasma supply-chain npm, NetScaler SAML, Cisco SD-WAN sans patch — cinq fronts simultanés sur l'infrastructure critique.

## 🏆 Top 3 de la semaine

- **Angular 22 GA — Signal Forms, MCP server et TypeScript 6** : la sortie la plus structurante de l'année pour l'écosystème Angular. Signal Forms, `httpResource`, Selectorless Components et Angular Aria passent stables. Le MCP server Angular (stable en v22) permet aux agents IA de piloter le dev server et d'itérer en boucle auto-correctrice. TypeScript 6 devient obligatoire pour tout projet Angular — migration non négociable avant de bumper en v22.
- **MiniMax M3 — premier open-weight à rivaliser avec le top propriétaire** : 59 % sur SWE-Bench Pro (devant GPT-5.5), 83,5 % sur BrowseComp (devant Claude Opus 4.7), architecture MSA qui divise par 20 le coût de calcul à 1M de tokens. C'est le premier open-weight qui change réellement le calcul build-vs-buy pour un pipeline de coding agentique.
- **Semaine rouge en sécurité infra** : Netlogon CVE-2026-41089 (RCE non authentifiée sur tous les DCs, exploitation confirmée), Miasma npm (32 paquets Red Hat compromis, 117K DL/semaine), NetScaler CVE-2026-3055 (exploitation SAML à grande échelle, CVSS 9.3), VS Code zero-day OAuth et Cisco SD-WAN sans patch — cinq vecteurs critiques actifs simultanément.

## 🅰️ Angular — Bilan de la semaine

### Tendance
Semaine historique pour Angular : le GA de la v22 stabilise l'architecture signal-first, et le MCP server transforme l'outillage IA de l'écosystème — mais TypeScript 6 constitue la rupture opérationnelle réelle pour les équipes.

### Sujets marquants

**Angular 22 GA — Signal Forms, Selectorless et httpResource stables** (mercredi 3 juin)

**Source :** InfoQ — https://www.infoq.com/news/2026/04/angular-compiler-rust/

Toutes les API signal-first longtemps expérimentales passent stables en v22 : **Signal Forms** (validation et état réactifs, fusion Reactive Forms + signals), **Selectorless Components** (import direct sans sélecteur string), **`resource` et `httpResource`** (data fetching réactif piloté par signals), **Angular Aria** (primitives d'accessibilité). En bonus, le compilateur expérimental Oxc (Rust, VoidZero) annonce des builds jusqu'à **20× plus rapides**. Ces API sont désormais utilisables en production sans flag expérimental.

**Angular MCP server stable — l'IA pilote le dev server en boucle** (vendredi 5 juin)

**Source :** Angular Blog — https://blog.angular.dev/angular-in-2026-mid-year-reality-check-signals-and-ai-code-quality-ff37df480574

Le MCP server Angular (stable en v22) expose des outils opérationnels : `devserver.wait_for_build`, `devserver.start/stop`, `onpush_zoneless_migration`, `modernize`. Les agents peuvent désormais lancer le dev server, observer les erreurs de build et itérer en boucle auto-correctrice. Les **Angular Agent Skills** (`github.com/angular/skills`) permettent d'injecter du contexte v22 dans n'importe quel agent. Alerte pratique : les LLMs entraînés avant fin 2025 génèrent encore `NgModule`, `ChangeDetectionStrategy.Default`, `@Injectable` au lieu de `@Service()` — un prompt système explicite ou le MCP server corrige ça en 30 secondes.

**Migration communauté — TypeScript 6 obligatoire, OnPush uniquement CLI, Node 26** (samedi 6 juin)

**Source :** Angular Addicts — https://www.angularaddicts.com/p/angular-addicts-48-typescript-6-on-push-as-default

Trois jours après le GA, les premiers retours convergent sur les mêmes points de friction. **TypeScript 6** est la vraie rupture : incompatible avec TS 5.x, toutes les options `tsconfig.json` dépréciées doivent être révisées. `ng update @angular/core` gère la plupart des ajustements mais des passes manuelles restent nécessaires. **OnPush par défaut** ne concerne que les _nouveaux_ composants générés via CLI — les fichiers existants ne sont pas modifiés. **Node 20 est supprimé**, Node 26 recommandé — valide les addons natifs avant de migrer ton pipeline CI.

## 🔷 CSharp / .NET — Bilan de la semaine

### Tendance
Semaine dominée par le virage agentique de Microsoft : le Build 2026 positionne Windows et Azure comme plateformes d'agents, l'agent de modernisation Copilot industrialise la dette technique .NET, et VS Code 1.123 lève les dernières barrières pour les environnements restreints.

### Sujets marquants

**Microsoft Build 2026 — Windows devient une plateforme d'agents** (mardi 2 juin)

**Source :** Windows News — https://windowsnews.ai/article/build-2026-microsoft-makes-windows-an-agent-platform-for-ai-developers.420496

La keynote de Satya Nadella repositionne Windows et Azure comme hôtes d'agents autonomes. Nouveautés concrètes : **Azure Linux 4.0** en préversion publique, **Azure Container Linux GA** (OS minimal pour conteneurs AI-native), **Azure Agent Mesh** (orchestration multi-agents côté cloud), **WSL 3** et **Windows Agent Store**. Le **Microsoft Agent Framework** (SDK .NET/Python) est GA depuis avril — voie officielle pour construire des agents en .NET sans risque de RC.

**Agent Copilot de modernisation .NET — Web Forms → Blazor, Aspire** (jeudi 4 juin)

**Source :** Visual Studio Blog — https://devblogs.microsoft.com/visualstudio/whats-coming-next-in-visual-studio-our-microsoft-build-2026-announcements/

Microsoft détaille un agent de modernisation applicative dans Visual Studio : **upgrade automatisé vers .NET 10/C# 14** avec analyse des breaking changes, **migration Web Forms → Blazor** (conversion `.aspx` et code-behind), **greffe d'Aspire** sur apps existantes pour orchestration multi-services et télémétrie OpenTelemetry. Disponibilité « cet été » — teste sur branche isolée dès qu'une preview arrive. Un chantier de migration Web Forms qui prendrait plusieurs semaines devient une revue assistée.

**VS Code 1.123 — sessions agent parallèles, 1M tokens, BYOK air-gapped** (samedi 6 juin)

**Source :** Visual Studio Code — https://code.visualstudio.com/updates/v1_123

VS Code 1.123 (sorti le 3 juin) marque un palier dans les features agent : **sessions agent parallèles** (comparer deux approches côte à côte), **sync cross-machines** de l'historique agent, **contexte 1M tokens** (Anthropic et OpenAI), **BYOK sans GitHub Sign-in** (clé API directement dans les settings, applicable aux environnements air-gapped et VMs isolées), **research agent** (croise codebase, repos GitHub et web). Le BYOK est la feature la plus directement actionnable pour les environnements .NET ou Angular avec contraintes réseau ou SSO custom.

## 🤖 IA Open Source — Bilan de la semaine

### Tendance
Semaine record en open-weight : MiniMax M3 franchit le plafond du propriétaire sur le coding, Holo3.1 ouvre le computer use en local, et Microsoft sort ses premiers LLMs propres — sans oublier une dizaine d'autres sorties MoE permissives qui renforcent l'écosystème self-hosted.

### Sujets marquants

**MiniMax M3 — 59 % SWE-Bench Pro, 1M contexte, MSA** (lundi 1er juin, confirmé vendredi 5)

**Source :** MiniMax Blog — https://www.minimax.io/blog/minimax-m3

Premier open-weight à combiner frontier coding, 1M de tokens de contexte et multimodalité native. **59 % sur SWE-Bench Pro** (devant GPT-5.5 à 58,6 %), **83,5 % sur BrowseComp** (devant Claude Opus 4.7 à 79,3 %). Architecture **MSA (Multi-Scale Attention)** : ×9 sur le prefill, ×15 sur le décodage à contexte long. Poids annoncés sur Hugging Face dans les ~10 jours après le 1er juin. API disponible depuis le 1er juin. Candidat sérieux pour self-hoster un agent CI sur un contexte de codebase entier — mais attends les poids et un bench tiers.

**Holo3.1 — computer use open-weight local, FP8/GGUF, AndroidWorld 79,3 %** (samedi 6 juin)

**Source :** Hugging Face Blog — https://huggingface.co/blog/Hcompany/holo31

H Company publie Holo3.1 en 4 tailles (0.8B, 4B, 9B, 35B-A3B) avec quantification FP8, NVFP4 et **Q4 GGUF compatible llama.cpp et Apple Silicon**. **AndroidWorld** : 67 % → **79,3 %** (+12,3 pts) pour le 35B. Support **function calling natif** en parallèle de la sortie JSON. Le 9B est le sweet spot coût/perf pour des pipelines CI qui automatisent des tests de navigation. Le Q4 GGUF sur Apple Silicon supprime la dépendance cloud pour les workflows de computer use privés.

**Microsoft MAI-Code-1-Flash + MAI-Thinking-1 — premiers LLMs propres Microsoft** (samedi 6 juin)

**Source :** CNBC — https://www.cnbc.com/2026/06/02/microsoft-unveils-new-ai-models-lessen-reliance-on-openai-lower-costs.html

Microsoft annonce au Build 2026 ses premiers modèles IA en propre : **MAI-Code-1-Flash** (génération de code, rapide et économique, intégré à Copilot et pipelines CI) et **MAI-Thinking-1** (reasoning haute performance à faible coût). Objectif déclaré : réduire le coût par token pour les cas d'usage répétitifs haute-fréquence sur Azure. Si la tarification est significativement inférieure à GPT-4o pour le boilerplate CRUD ou les tests unitaires, ces modèles pourraient devenir les defaults dans les pipelines Copilot d'entreprise.

**Mellum2 (JetBrains) — MoE 12B-A2.5B Apache 2.0 pour l'infra agentique** (mardi 2 juin)

**Source :** JetBrains AI Blog — https://blog.jetbrains.com/ai/2026/06/mellum2-goes-open-source-a-fast-model-for-ai-workflows/

MoE 12B avec 2,5B actifs par token, **Apache 2.0**, variantes Base/Instruct/Thinking sur Hugging Face. Taillé pour la couche infra : routage, RAG, sous-agents, on-premise. Self-hostable sans frein juridique pour du code interne privé — GPU modeste suffisant grâce au MoE.

**Ideogram 4 — text-to-image open-weight, 9,3 Md, prompting JSON** (jeudi 4 juin)

**Source :** Ideogram Blog — https://ideogram.ai/blog/ideogram-4.0/

Premier studio text-to-image à ouvrir ses poids : 9,3 Md de paramètres (DiT), encodeur `Qwen3-VL-8B`, interface JSON structurée (bounding-boxes, palette, 2K natif), poids `nf4`/`fp8` sur Hugging Face. En tête des labs open sur Design Arena. **Attention : licence non-commerciale** — vérifie avant tout usage client.

## 📡 Tech Overview — Bilan de la semaine

### Tendance
Semaine exceptionnellement chargée : l'infrastructure critique (DCs Windows, SAML Citrix, VPN PAN-OS, Linux kernel, npm) est attaquée sur cinq fronts simultanément, avec des exploits publics ou confirmés in-the-wild pour chaque vecteur.

### Sujets marquants

**Netlogon CVE-2026-41089 — RCE non auth sur tous les DCs Windows, exploitée** (jeudi 4 juin)

**Source :** Help Net Security — https://www.helpnetsecurity.com/2026/06/01/windows-netlogon-rce-exploited-cve-2026-41089/

Stack-based buffer overflow dans Netlogon — **aucune authentification requise**, exécution en SYSTEM directement sur le contrôleur de domaine. Tous Windows Server 2012 → 2025 affectés. Exploitation in-the-wild confirmée depuis le 29 mai. Correctif disponible depuis le Patch Tuesday du 12 mai. Priorité absolue : un seul DC non patché = AD compromis. Patche tous les DC dans une même fenêtre de maintenance.

**Miasma — supply-chain npm, 32 paquets Red Hat compromis, 117K DL/semaine** (jeudi 4 juin)

**Source :** Wiz Blog — https://www.wiz.io/blog/miasma-supply-chain-attack-targeting-redhat-npm-packages

Après compromission d'un compte GitHub Red Hat, 32 paquets npm (`RedHatInsights/frontend-components`, `javascript-clients`, `platform-frontend-ai-toolkit`), 96 versions, ~117K téléchargements hebdomadaires. Le malware s'exécute pendant `npm install` via un script `preinstall` piégé — invisible, avant le code applicatif. Cible : secrets AWS, tokens cloud, credentials CI/CD. Action : épingle tes lockfiles, `npm ci --ignore-scripts`, fais tourner tes credentials si tu consommes des paquets `@redhat*` depuis le 1er juin.

**Citrix NetScaler CVE-2026-3055 — SAML IDP, exploitation à grande échelle** (jeudi 4 juin)

**Source :** Rapid7 — https://www.rapid7.com/blog/post/etr-cve-2026-3055-citrix-netscaler-adc-and-netscaler-gateway-out-of-bounds-read/

Out-of-bounds read (CVSS 9.3) dans NetScaler ADC/Gateway en mode SAML IDP. Un SAMLRequest forgé sans `AssertionConsumerServiceURL` provoque une fuite mémoire exposant tokens de session actifs et credentials en transit. Exploitation à grande échelle confirmée par Fortinet. Applique le firmware corrigé, révoque les sessions actives, surveille `/saml/login` sans `AssertionConsumerServiceURL` dans tes logs.

**VS Code zero-day — vol de tokens GitHub OAuth via github.dev** (vendredi 5 juin)

**Source :** Bleeping Computer — https://www.bleepingcomputer.com/news/security/vs-code-zero-day-lets-hackers-steal-github-tokens-in-one-click/

Via `postMessage` entre webview et fenêtre principale de VS Code, un clic sur un lien piégé installe une extension malveillante et exfiltre le token GitHub OAuth — donnant accès en lecture/écriture à tous les dépôts privés. Correctif côté `github.dev` le 3 juin (aucune action requise). VS Code Desktop reste partiellement exposé via notebooks. Inspecte tes sessions GitHub actives si tu as utilisé `github.dev` récemment.

**Cisco SD-WAN CVE-2026-20245 — 7e zero-day 2026, sans patch** (samedi 6 juin)

**Source :** Recap global du 6 juin — `Recap/2026-06-06_recap.md`

Cisco confirme un 7e zero-day SD-WAN exploité en 2026, sans patch disponible. L'exploitation requiert des credentials netadmin — souvent récupérables via les failles précédentes de la série. Si tu as des équipements SD-WAN : audite les credentials netadmin, surveille les IoC publiés par Mandiant.
