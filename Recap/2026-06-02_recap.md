# Digest Tech — Recap global du mardi 2 juin 2026

Sept sujets retenus sur trois thématiques actives (Angular est calme aujourd'hui). Deux mouvements de fond traversent la journée : l'écosystème Microsoft bascule franchement vers l'agentique au Build 2026, et la vague des modèles MoE open-weight et permissifs continue, avec un nouveau venu côté code. Côté sécurité, deux échéances de patch tombent cette semaine, dont une dès demain.

## Frameworks

Rien de neuf côté Angular : la dernière version stable reste Angular 22 (couverte le 1er juin) et le blog officiel est muet depuis le 22 mai. Côté Microsoft, **Build 2026** (2-3 juin, San Francisco) repositionne Windows et Azure comme plateformes d'agents : **Azure Linux 4.0** en préversion publique, **Azure Container Linux** en GA, et l'arrivée de WSL 3, Azure Agent Mesh et du Windows Agent Store. Le **Microsoft Agent Framework** (SDK .NET/Python, GA depuis avril) reste la brique de référence pour bâtir des agents.

## IA

**JetBrains ouvre Mellum2** en Apache 2.0 : un MoE 12B à 2,5B actifs, pensé pour la couche infra agentique (routage, RAG, sous-agents, on-premise) plutôt que le chat. Deux sorties chinoises confirment la tendance edge/multimodale : **MiniCPM5-1B** (on-device, tool-calling) et **Keye-VL 2.0** (VLM MoE 30B-A3B). Le dénominateur commun : des MoE compacts, permissifs et self-hostables.

## Sécurité

La CISA exige la correction de deux failles **Microsoft Defender** exploitées (CVE-2026-41091 / 45498) pour le **3 juin**. La faille **SQL injection de Drupal** (CVE-2026-9082) reste massivement exploitée et ne frappe que les sites adossés à **PostgreSQL** — un rappel sur la validation des clés de payload, pas seulement des valeurs.

## À retenir si tu n'as qu'une minute

- **Patche Defender d'ici demain** : moteur cible `1.1.26040.8`, sur serveurs Windows et machines CI.
- **Mellum2** est self-hostable en Apache 2.0 — candidat sérieux pour une brique de code privée.
- Si tu opères du **Drupal sur PostgreSQL**, applique le correctif SA-CORE-2026-004 sans attendre.
- **Microsoft Agent Framework** est GA : adopte-le pour tes agents .NET sans risque de RC.
