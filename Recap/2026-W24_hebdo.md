# Digest Tech — Récap Semaine W24 (2026-06-08 → 2026-06-14)

La semaine 24 s'est jouée en deux temps. Côté IA, le début de semaine a parlé efficience mémoire (Gemma 4 QAT, vLLM/EAGLE 3.1, modèles de code self-hostables) avant que la **diffusion** ne fasse irruption dans l'inférence LLM en fin de semaine — `DiffusionGemma` devient le premier modèle par diffusion nativement supporté dans vLLM, jusqu'à 4× plus rapide qu'un autorégressif. Côté sécurité, après un Patch Tuesday record (~208 CVE, 3 zero-days), la menace a glissé vers ce que ta CI et tes agents *ingèrent* : worm npm `node-gyp`, RCE Langflow exploitée et non patchée, et « Agentjacking » qui détourne un agent de code via un faux event Sentry. Pendant ce temps, .NET 11 Preview 5 stabilise des nouveautés de langage majeures (union types, closed hierarchies) tandis qu'Angular reste en pause post-GA v22. Deux jours (vendredi 12, samedi 13) n'ont pas de digest cette semaine.

## 🏆 Top 3 de la semaine

- **Supply chain & agents IA sous assaut** : worm npm `node-gyp` (57 paquets, code exécuté à `npm install`, vol de secrets CI/cloud), RCE Langflow `CVE-2026-5027` exploitée et sans patch (~7 000 instances exposées), et **Agentjacking** (un faux event Sentry pousse ton agent de code à exécuter du code via MCP). C'est la menace la plus directe pour ton quotidien de dev cette semaine.
- **.NET 11 Preview 5** : C# gagne les **union types/patterns**, les **closed hierarchies** (exhaustivité de `switch` garantie) et un `unsafe` explicite ; EF Core bascule en compat SQL Server 2022 par défaut et introduit l'alerte **EF1004**. De quoi repenser ta modélisation de domaine — sur une branche, la GA est en novembre 2026.
- **DiffusionGemma — la diffusion entre dans l'inférence LLM** : Google ouvre (Apache 2.0) le premier LLM par diffusion nativement supporté dans vLLM, > 1000 tok/s sur un H100, jusqu'à 4× un autorégressif. Xiaomi (MiMo FP4 « DFlash ») pousse la même logique la même semaine : le débit devient le terrain de bataille, devant la course au score.

## 🔷 CSharp / .NET — Bilan de la semaine

### Tendance
Pas de GA, mais une semaine chargée : .NET 11 avance vers la stabilité (Preview 5) et le servicing de sécurité de juin rejoue les correctifs sur toutes les branches supportées.

### Sujets marquants
- **.NET 11 Preview 5 — langage** (9 juin) : `closed` hierarchies, **union types & patterns** de première classe, `unsafe` plus explicite ; côté libs, JSON Lines dans `System.Text.Json`, full outer joins LINQ, échange de clés X25519. Avant-dernière préversion avant la GA de novembre — testable sur branche dès maintenant. Source : .NET Blog — https://devblogs.microsoft.com/dotnet/dotnet-11-preview-5/
- **EF Core (Preview 5) — changements de défaut** : compat **SQL Server 2022 par défaut** (le plan d'exécution peut bouger, valide tes perfs), warning **EF1004** quand une requête async tourne en réalité en synchrone, checks de vulnérabilité/EOL **au build**, et template MCP Server dans `dotnet new`. Source : .NET Blog — https://devblogs.microsoft.com/dotnet/dotnet-11-preview-5/
- **EF Core — recherche vectorielle SQL Server 2025** : `VectorSearch()` + `WithApproximate()` se traduisent en `WITH APPROXIMATE`, et les colonnes JSON deviennent first-class. Utile pour ton RAG, mais compare à ton réflexe **pgvector** avant de t'engager. Source : Microsoft Learn (EF Core – What's New) — https://learn.microsoft.com/en-us/ef/core/what-is-new/
- **Servicing .NET de juin** (9 juin) : correctifs de sécurité sur .NET 8/9/10 alignés sur le Patch Tuesday. Un recompile ne suffit pas : repull les images Docker `mcr.microsoft.com/dotnet/*` et bumpe le SDK sur tes agents CI. Source : .NET Blog — https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-june-2026-servicing-updates/
- **EF Core 11 Preview 4 — outillage migrations** : `dotnet ef database update --add` crée *et* applique une migration en une commande (Roslyn au runtime, idéal Aspire/conteneurs), colonnes temporelles exposées en propriétés CLR. Source : .NET Blog — https://devblogs.microsoft.com/dotnet/dotnet-11-preview-4/

Sources : VentureBeat — https://venturebeat.com/technology/cohere-open-sources-a-coding-agent-that-runs-on-a-single-h100 ; The New Stack — https://thenewstack.io/jetbrains-mellum2-open-source-coding-model/

Source : MarkTechPost — https://www.marktechpost.com/2026/06/12/moonshot-ai-releases-kimi-k2-7-code-a-coding-model-reporting-21-8-on-kimi-code-bench-v2-over-k2-6/

## 📡 Tech Overview — Bilan de la semaine

### Tendance
Semaine sous très haute tension sécurité : Patch Tuesday record, puis bascule vers la **supply chain et les agents IA** — ce que ta CI et ton agent ingèrent devient le maillon faible. Outillage front/ORM en début de semaine.

### Sujets marquants
- **Patch Tuesday de juin — record (~208 CVE, 3 zero-days)** : dont **CVE-2026-45657** (RCE noyau TCP/IP, CVSS 9.8, profil **wormable** : réseau / sans auth / sans interaction) et **CVE-2026-41091** (EoP Defender, activement exploitée). Patche tes hôtes Windows sans attendre ta fenêtre habituelle. Sources : BleepingComputer — https://www.bleepingcomputer.com/news/microsoft/microsoft-june-2026-patch-tuesday-fixes-3-zero-day-200-flaws/ ; Zero Day Initiative — https://www.zerodayinitiative.com/blog/2026/6/9/the-june-2026-security-update-review
- **Langflow CVE-2026-5027** (10 juin) : path traversal sur `POST /api/v2/files` → **RCE non authentifiée**, exploitée in-the-wild, **~7 000 instances exposées**, **aucun patch**. Sors toute instance d'Internet et coupe l'auto-login. Source : The Hacker News — https://thehackernews.com/2026/06/unpatched-langflow-flaw-cve-2026-5027.html
- **Worm npm `node-gyp`** : 57 paquets piégés, code exécuté à `npm install` (build natif), vol de secrets npm/GitHub/AWS/GCP/Azure/Vault/K8s, caractère auto-propagateur. Active `--ignore-scripts`, épingle (`npm ci` + lockfile), builds en conteneurs éphémères. Source : Snyk — https://snyk.io/blog/node-gyp-supply-chain-compromise-self-propagating-npm-worm-binding-gyp/
- **Agentjacking** (12 juin) : un faux event Sentry détourne ton agent de code via le serveur MCP Sentry et contourne EDR/WAF/IAM (85 % de réussite sur 100+ orgs testées). Traite toute sortie MCP comme une entrée non fiable. Source : The Hacker News — https://thehackernews.com/2026/06/agentjacking-attack-tricks-ai-coding.html
- **Vague d'exploits infra + outillage** : Check Point `CVE-2026-50751` (bypass VPN IKEv1, lié au ransomware Qilin), SAP `CVE-2026-44748` (SAML XML Signature Wrapping, 9.9), Veeam `CVE-2026-44963` (RCE backup, 9.4), zero-day Chrome V8 `CVE-2026-11645`, release de sécurité OpenSSL. Côté outils : **TypeORM 1.0** (`DataSource` partout, requêtes paramétrées tous drivers, Node 20 min, codemod) et **Next.js 16.2** (serveur de dev ~400 % plus rapide). Sources : Check Point — https://blog.checkpoint.com/security/check-point-releases-important-hotfix-for-vulnerabilities-in-deprecated-ikev1-vpn-protocol/ ; InfoQ (TypeORM) — https://www.infoq.com/news/2026/06/typeorm-1-released/
