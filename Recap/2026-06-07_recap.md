# Digest Tech — Recap global du dimanche 7 juin 2026

Week-end calme mais utile : 5 sujets retenus sur 4 thématiques. L'actualité se concentre sur l'outillage et l'infrastructure plutôt que sur de nouveaux modèles ou frameworks. Trois mouvements de fond : une release base de données majeure (PostgreSQL 19 entre en beta), la consolidation de l'inférence locale (Ollama, transformers), et la généralisation des SDK agentiques (GitHub Copilot). Angular et .NET sont en pause post-GA / inter-préversions.

## Base de données

`PostgreSQL 19 Beta 1` (4 juin) ouvre la phase de test publique : autovacuum parallèle, I/O asynchrone auto-scalé via `io_min_workers` / `io_max_workers`, read-ahead amélioré, inserts plus rapides et nouvelle option `EXPLAIN (ANALYZE, IO)`. GA visée septembre/octobre 2026 — le bon moment pour benchmarker tes grosses tables.

## IA & inférence locale

Pas de nouveau modèle phare ce week-end, mais des briques plus solides. `Ollama 0.30` réintègre `llama.cpp` aux côtés de MLX et élargit le support matériel (NVIDIA, GGUF custom) ; le patch `0.30.5` corrige les crashs Gemma 4 12B. `Transformers v5.10.1` ajoute Gemma 4 Unified, DeepSeek-OCR-2, Sapiens2 et Mellum.

## Sécurité

Cisco corrige `CVE-2026-20230`, une SSRF non authentifiée du WebDialer de Unified CM permettant une escalade vers root. CVSS 8.6 mais classée CRITICAL, avec PoC public — mitigation immédiate : désactiver WebDialer.

## Outillage dev

Le `GitHub Copilot SDK` passe en disponibilité générale (2 juin) : API agentique embarquable, support MCP natif, sandboxes isolées. À cadrer côté budget depuis la bascule vers les GitHub AI Credits.

## À retenir si tu n'as qu'une minute

- **Monte un env de test PostgreSQL 19 Beta 1** pour valider migrations et autovacuum parallèle avant la GA.
- **Si tu as un Cisco Unified CM**, désactive WebDialer ou applique le COP : PoC public = exploitation imminente.
- **Pour l'inférence locale**, passe à Ollama `0.30.5` minimum (crashs Gemma 4 12B corrigés).
- **Angular et .NET** : rien à migrer, profites-en pour finir tes chantiers v22 / tester EF Core 11 Preview 4.
