# Digest Tech — Recap global du vendredi 5 juin 2026

Cinq sujets retenus sur quatre thématiques aujourd'hui. Au lendemain de la GA Angular v22, la communauté se concentre sur deux urgences pratiques : l'outillage IA qui génère encore du code obsolète, et la préparation des apps au zoneless. En sécurité, un zero-day VS Code touche directement les workflows GitHub, et Google clôt son Patch Tuesday Android de juin avec 124 correctifs dont un activement exploité. Côté IA ouverte, MiniMax M3 s'impose comme le premier open-weight à combiner frontier coding et 1M de tokens de contexte.

## Angular — bilan mi-2026 et outillage IA

La newsletter officielle du 5 juin pose deux questions urgentes pour tout dev Angular : ton assistant IA code-t-il encore l'ancien Angular ? Et ton app est-elle vraiment prête pour le zoneless ? L'article de Sonu Kapoor sur CodeMag détaille comment le Model Context Protocol redéfinit l'outillage, passant du scaffolding CLI à un agent qui raisonne sur le workspace entier — avec des boucles de feedback sur le build server.

## IA — MiniMax M3, premier open-weight frontier

MiniMax publie M3 : 1M de tokens de contexte, SWE-Bench Pro à 59%, architecture MSA qui divise par 20 le coût de calcul à contexte long. C'est le premier open-weight à tenir tête aux modèles propriétaires top-tier sur le coding (devant GPT-5.5 et Gemini 3.1 Pro) et le web browsing (devant Claude Opus 4.7).

## Tech — VS Code et Android dans l'œil du cyclone

Un zero-day VS Code permet de voler un token GitHub OAuth en un seul clic via `github.dev` — Microsoft a patché en urgence le 3 juin. Par ailleurs, le Patch Tuesday Android de juin couvre 124 failles dont CVE-2025-48595 (escalade de privilèges sans interaction, activement exploitée, au catalogue CISA KEV avec deadline aujourd'hui pour les agences fédérales).

## À retenir si tu n'as qu'une minute

- **Vérifie que ton LLM connaît Angular v22** : les modèles entraînés avant fin 2025 génèrent encore du code `NgModule`-first et `ChangeDetectionStrategy.Default` — ajoute une règle explicite dans ton prompt système.
- **Auditre ta migration zoneless** avec la checklist d'Alain Chautard avant de planifier le chantier post-v22.
- **Inspecte tes sessions GitHub actives** si tu as utilisé `github.dev` récemment et cliqué sur des liens non vérifiés.
- **MiniMax M3** : à intégrer dans tes comparatifs si tu évalues des alternatives open-weight à GPT-5.5 pour du coding agentic — les poids arrivent dans ~10 jours sur Hugging Face.
