# CSharp — Détail du samedi 6 juin 2026

## 1. VS Code 1.123 — Agents en parallèle, contexte 1M tokens, BYOK air-gapped, MCP déduplication

**Source :** Visual Studio Code — https://code.visualstudio.com/updates/v1_123
**Date :** 3 juin 2026

### Contexte

VS Code 1.123 est la release de juin 2026. Elle fait suite à plusieurs mois de montée en puissance des fonctionnalités agent dans l'éditeur, mais cette version marque un palier : pour la première fois, la plateforme supporte des sessions agent parallèles visibles côte à côte, et lève la dépendance à GitHub Sign-in pour les usages BYOK — ce qui ouvre VS Code à des contextes entreprise avec des contraintes réseau ou SSO strictes.

### Ce qui change concrètement

**Fenêtres agent parallèles :**
- Ouvre plusieurs sessions agent dans des panneaux distincts. Utile pour comparer deux approches générées par l'IA sur la même tâche, ou pour maintenir un agent de review pendant qu'un autre code.

**Sync des sessions cross-machines :**
- L'historique des conversations agent est synchronisé automatiquement entre appareils. Recherche full-text dans l'historique disponible.

**Contexte 1M tokens :**
- Support des modèles Anthropic et OpenAI avec fenêtres de contexte 1M tokens. À combiner avec les grandes codebases sans tronquer manuellement.

**BYOK sans GitHub Sign-in :**
- Fournis ta clé API directement dans les settings. Chat, tools et serveurs MCP fonctionnent sans authentification GitHub. Applicable aux environnements air-gapped, aux VMs isolées, aux CI/CD sans accès externe.

**Research agent :**
- Lance un agent de recherche approfondie sur un topic. Il croise ta codebase, des repos GitHub publics et le web, et produit un rapport Markdown cité.

**MCP déduplication :**
- Si deux extensions exposent un serveur MCP sous le même nom, seul le plus spécifique (extension la plus récente ou prioritaire) reste actif par défaut. Contrôle via `@mcp @installed` dans la vue Extensions.

### Pourquoi ça compte pour toi

Le BYOK sans GitHub Sign-in est la feature la plus directement actionnable : si tu as des projets .NET ou Angular dans un environnement restreint (no internet, intranet only, SSO custom), tu peux maintenant utiliser les features IA de VS Code sans demander d'exceptions réseau. Les sessions parallèles valent aussi la peine d'être testées pour les revues de PR lourdes — un agent review + un agent refacto côte à côte.
