# Synthèse Veille C# / .NET / ASP.NET — 1er mai 2026

> Couverture des dernières 24 heures (30 avril – 1er mai 2026)

## En bref

La grande nouvelle du jour est la **sortie d'Ubuntu 26.04 LTS « Resolute Raccoon »** qui embarque officiellement **.NET 10** dans son dépôt principal, accompagnée de nouvelles images conteneurs `-resolute` et de la prise en charge native d'AOT pour Linux. Le sujet sécurité **CVE-2026-40372** continue d'occuper les gestionnaires d'infrastructure, avec des avis de remédiation publiés cette semaine. Côté outillage, **Visual Studio 2026 v18.5.1** consolide l'intégration des **agents cloud GitHub Copilot** (assigner une tâche, fermer l'IDE, recevoir une PR). En préparation de juin, **DevExpress publie sa feuille de route Blazor v26.1** avec mode contraste élevé et intégrations Fluent UI, tandis que Microsoft confirme le passage de **GitHub Copilot à un modèle de facturation à l'usage le 1er juin 2026**.

## Top 5 à retenir

1. **Ubuntu 26.04 LTS embarque .NET 10 nativement** — Installable directement via `apt install dotnet-sdk-10.0`. Nouvelles images Docker `-resolute` officielles, support AOT natif, et PPA `dotnet-backports` pour .NET 8/9. Support assuré jusqu'en avril 2031.
2. **CVE-2026-40372 : phase de rotation des clés** — Au-delà du patch 10.0.7, les CSIRT recommandent maintenant la **rotation immédiate du Data Protection key ring** pour invalider tout cookie qui aurait pu être forgé avant la mise à jour. Avis officiels Université York et Security Boulevard publiés cette semaine.
3. **VS 2026 + Cloud Agent : « Assign a Task, Close the IDE, Get a PR »** — L'update v18.5.1 unifie l'expérience VS Code et VS 2026 autour des agents distants GitHub Copilot, qui exécutent les tâches longues sur infra cloud puis ouvrent une PR.
4. **DevExpress Blazor v26.1 (juin) — Feuille de route publiée** — Support du mode contraste élevé Windows, nouveaux composants Fluent UI, et amélioration de la gestion des thèmes sombres pour les Blazor Web Apps en .NET 10.
5. **GitHub Copilot → facturation à l'usage le 1er juin 2026** — Inquiétudes de la communauté .NET sur la prévisibilité des coûts, l'accès aux modèles premium (GPT-5, Claude 4.6) et les quotas mensuels inclus dans les plans Pro/Business.

## Action recommandée

Si vous gérez des serveurs Linux exécutant ASP.NET Core, **planifiez la migration vers Ubuntu 26.04 LTS** dans les semaines à venir : c'est la première LTS Ubuntu qui ship .NET 10 dans le dépôt officiel, supprimant le besoin du PPA Microsoft pour les nouvelles installations. Pour les déploiements existants en production, vérifiez qu'après l'application du patch **.NET 10.0.7**, vous avez bien procédé à la **rotation des clés Data Protection** comme recommandé par les nouveaux avis CSIRT.
