# Synthèse Veille — Angular & TypeScript

**Date :** 1er mai 2026
**Périmètre :** actualités des dernières 24 h (et derniers jours significatifs)

---

## En bref

Deux tendances dominent l'actualité de l'écosystème front-end cette semaine :

- **TypeScript 7.0 Beta** vient d'être officiellement annoncé par Microsoft (21 avril 2026). Le compilateur a été porté en Go (« Project Corsa ») et tourne environ **10× plus vite** que TypeScript 6.0, avec une consommation mémoire quasiment divisée par deux.
- **Angular 22** est attendu autour de **mai 2026**, dans la lignée de la cadence semestrielle de l'équipe. Cette version doit stabiliser les **Signal Forms**, généraliser l'approche **Signal-First**, introduire les **composants selectorless** et basculer **OnPush** par défaut. La dernière version supportée à ce jour reste **Angular 21.2.10** (publiée le 22 avril 2026).

---

## TypeScript — points clés

TypeScript 7.0 Beta s'installe via `npm install -D @typescript/native-preview@beta` et s'exécute avec la commande `tsgo`. Le comportement de typage est **structurellement identique** à celui de TypeScript 6.0 : seul change le moteur. Les gains observés sur de gros codebases (VS Code, Sentry, etc.) confirment la promesse de Microsoft, avec des temps de build réduits d'un ordre de grandeur. Le support éditeur s'appuie désormais sur le **Language Server Protocol (LSP)**, ce qui ouvre la porte à un meilleur support hors VS Code.

## Angular — points clés

Angular continue sa mue vers une architecture **Signal-First** : Signal Forms (encore expérimentales en v21) deviennent stables en v22, les nouveaux projets sont **zoneless par défaut**, et **Vitest** est désormais le test runner par défaut (Karma/Jasmine restent supportés). La v22 ajoutera les **selectorless components**, le support de **TypeScript 5.9**, et de nouvelles primitives Signals (`debounced()`, `resource()`). Côté sécurité, des correctifs SSR (SSRF, header injection, open redirect via X-Forwarded-Prefix) avaient été poussés en février 2026 — à appliquer si ce n'est pas déjà fait.

## À retenir pour l'équipe

- Tester `tsgo` en local sur les projets Angular pour mesurer le gain (build + IDE) sans migration intrusive.
- Vérifier la version Angular utilisée : si l'on est encore en v19, anticiper la migration (fin de support **19 mai 2026**).
- Garder un œil sur l'annonce officielle d'Angular 22 attendue dans les semaines à venir, notamment pour valider la roadmap Signal Forms en production.
